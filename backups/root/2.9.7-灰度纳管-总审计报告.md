## 一、真凶：5 个键的「类型」与新宿主不符

模块按 `GmDialog.TYPES` 写（`putBoolean`/`putFloat`），宿主按**新类型**读 ⇒
MMKV 类型不符时**读回默认值** ⇒ 改动被静默丢弃（有 toast、模块 UI 也显示已保存，就是宿主不认）。

| 键 | 模块 2.9.6 | 宿主 2.5.1 | 修法（2.9.7） |
|---|---|---|---|
| `search_state_on_login` | `b` | **String**（`on`/`off`，默认 `keep`） | `b` → **`t`**（三态字符串开关） |
| `search_state_on_launch` | `b` | String | `b` → **`t`** |
| `search_state_on_manually_created_chat` | `b` | String | `b` → **`t`** |
| `search_state_on_automatically_created_chat` | `b` | String | `b` → **`t`** |
| `sse_auto_scroll_smooth_stiffness` | `f` | **Int**（默认 `Lf02;->V`=50） | `f` → **`i`** |

**取值语义**（`Laea;->s`）：`"on"`→开 / `"off"`→关 / **其它（含 `keep`、空）→ 不覆盖＝跟随下发**。
⇒ 与 2.9.4 修掉的 `volcengine_enabled`（b→s）同型：**升级宿主后只核了钩子点和键名，没核类型**。

2. 宿主 remote 键必须**翻页翻到 `hasMore=false`**（本次 200+200+24）——只取第一页会漏（我第一次就漏掉了 `welcome_msg`）；

4. 「`id` 版本键」用 `kv_remote_settings_id_` 前缀单独统计；
5. 偏门但好用：**smali 搜索直接用 getter 名**（`MMKV;->j(` / `->g(` / `->c(`），拿命中行号与 `kv_settings_<键>` 行号对齐 ⇒ 一次拿到"哪些键是 String"。

## 四、`kv_remote_settings_id_*`（84 个版本键）

- **是什么**：宿主给每个灰度项存的**服务端版本号**；`h02.b()` 的「(服务端键, id键)」成对表就是它。
  消费类读值形如
  ```java
  v = mmkv.<get>("kv_remote_settings_<k>", default); map.put(<k>, v);
  if (mmkv.contains("kv_remote_settings_id_<k>")) rj2.F(mmkv, "..._id_<k>", h02.p, <k>);
  ```
- **模块现状**：0 引用（搜 `kv_remote_settings_id_` 零命中）。
- **建议：不做成可编辑行。** 它是版本标记，改它没有功能收益，反而可能干扰宿主「这一项变没变」的判定。
  **显示有价值**（能判断服务端这次有没有更新某项）—— 而模块的下发 dump 已经显示：`{"id":…,"value":…}` 就是服务端原始推送格式（2.1.0 的 `vp4;<init>` 抓取点）。
- **反直觉的好消息**：pin 只保护**值键**、不保护 id 键 ⇒ 宿主照写 id，值被影子键挡住 ⇒ 下次服务端推同一个 id 时宿主认为"没变化" ⇒ **pin 更稳** ✅（不是缺陷）。

## 六、类型审计的两个坑（写下来省得下次再踩）

1. **JSON 整数 ≠ int**：`ds_key_types.txt` 里的 `i` 只是"JSON 数值"，可能是 int **也可能是 long**。
   权威判据永远是**宿主的 getter**。实例：`image_cache_invalidate_before` = `1777444200000`，
   宿主用 `java.lang.Long` + `MMKV.o(J,String)`（**putLong**）⇒ 模块的 `l`（long）**是对的** ✅。
2. **getter 名速查（2.5.1 实测）**：
   `c(String)Z`=getBool ｜ `g(String)I`=getInt ｜ `j(String)String`=getString ｜ `e(String,F)F`=getFloat ｜
   `o(J,String)V`=putLong ｜ `q(String,String)Z`=putString（下发路径，被 `GmMmkvHook` 拦） ｜
   `n(I,String)V`=putInt ｜ `r(String,Z)Z`=putBool ｜ `l()`=默认实例
