## 一、逆向结论：灰度机制长什么样

### 1. 配置系统 = MMKV 双前缀键值

R8 把业务类揉成了 `Lxx;`，但**字符串常量没法混淆**，于是暴露了配置系统：

| 键前缀 | 含义 | 优先级 |
|---|---|---|
| `kv_settings_<key>` | **本地值（用户覆盖）** | ⭐ 最高 |
| `kv_remote_settings_<key>` | 服务端下发的灰度值 | 中 |
| 内存缓存 `ConcurrentHashMap` | 进程内缓存 | 中 |
| 代码内默认值 | 兜底 | 低 |

### 2. 读取逻辑（实证：`Lbf4;-><init>` 的 smali）

```smali
const-string v0, "kv_settings_voice_input_enabled"
invoke-virtual {p2, v0}, Lcom/tencent/mmkv/MMKV;->contains(Ljava/lang/String;)Z
if-eqz v1, :cond_69
    invoke-virtual {p2, v0}, Lcom/tencent/mmkv/MMKV;->b(Ljava/lang/String;)Z   # decodeBool
    move-result p1
    goto :goto_97
:cond_69
    # 查内存缓存 ConcurrentHashMap
:cond_7c
    const-string v1, "kv_remote_settings_voice_input_enabled"
    invoke-virtual {p2, v1, v3}, Lcom/tencent/mmkv/MMKV;->c(Ljava/lang/String;Z)Z   # decodeBool(key, true)
    ...
```

👉 **只要往 MMKV 写 `kv_settings_<key>`，就会盖掉灰度值**，且写入点唯一、副作用小。

### 3. 存储承载

- 类 `Lnn9;`（字段 `d:Lcom/tencent/mmkv/MMKV;`）与 `Laz5;`（字段 `g`）持有 MMKV 实例
- 实例获取方式：`invoke-static {}, Lcom/tencent/mmkv/MMKV;->k()Lcom/tencent/mmkv/MMKV;` ← 即 **`MMKV.defaultMMKV()`**（静态单例）
- `MMKV` 类实现了 `android.content.SharedPreferences` 接口！

### 4. 关键红利：可以走 SharedPreferences 标准接口

| 想做的事 | 标准接口（**未混淆，可直接调**） |
|---|---|
| 取默认单例 | `MMKV;->k()`（混淆名，需用这个） |
| 判断键存在 | `SharedPreferences;->contains(String)Z` |
| 读 bool/int/long/str | `getBoolean` / `getInt` / `getLong` / `getString` |
| 写 | `edit()` → `putBoolean/putInt/putString` → `apply()` |
| 删（恢复灰度） | `edit()` → `remove(key)` → `apply()` |

因为接口方法名被强制保留，**不用碰 `b/c/f/i/j/p/q` 那堆混淆名**，实现风险大幅降低 ✅

### 5. 服务端灰度来源

`/api/v0/client/settings`（+ `/report`，带 `x-settings-token` 头）拉取远程配置，落到 MMKV 的 `kv_remote_settings_*`。我们的覆盖是**本地层**，不受服务端刷新影响。

## 三、总体方案

```
┌──────────────────────────────────────────────────────────┐
│ MainActivity (Compose 单 Activity)                        │
│   onCreate 末尾注入：decorView.setOnTouchListener(手势监听) │
│                                   │ 连点 7 次              │
│                                   ▼                       │
│  ┌─────────────────────────────────────────────┐          │
│  │ GrayManagerActivity（新增·纯 View，不走 Compose）│       │
│  │  标题：灰度管理器                              │       │
│  │  ├ 语音输入                 [Switch]  ↺      │        │
│  │  ├ 会话搜索                 [Switch]  ↺      │        │
│  │  ├ 补全超时(ms)             [ 30000 ] ↺      │        │
│  │  ├ 图片压缩格式             [ webp  ] ↺      │        │
│  │  └ …（配置项列表）                            │        │
│  └──────────────┬──────────────────────────────┘          │
│                 │ 读写 SharedPreferences 接口               │
│                 ▼                                          │
│        MMKV.defaultMMKV()  ← App 同一个实例                 │
│  写：kv_settings_<key>   删：remove → 回落远程灰度值          │
└──────────────────────────────────────────────────────────┘
```

**为什么这样设计**

1. **不碰 Compose**：设置页 UI 全是 R8 混淆后的 Composable（`Lyq3;->h0` 之类），改一行要重排寄存器，成本爆炸。改为在 MainActivity 注入手势 → 起一个纯 View 的子 Activity，零 Compose 依赖。
2. **不碰业务逻辑**：不需要改任何功能判断点。因为 `kv_settings_*` 天然是"最高优先级覆盖层"，写进去就等于灰度开关被人工拨动。
3. **接口化读写**：MMKV 的方法名被混淆（`b/c/f/i/j/p/q`），但 `SharedPreferences` 接口方法名保留，走接口最稳。

### 5.1 GrayManagerActivity（Java 参考实现）

> 最终以 Smali 形式写入；此处给出等价 Java 便于评审。

```java
package com.deepseek.chat.ga;

import android.app.Activity;
import android.content.SharedPreferences;
import android.os.Bundle;
import android.text.InputType;
import android.view.View;
import android.view.ViewGroup;
import android.widget.*;

import com.tencent.mmkv.MMKV;

public class GrayManagerActivity extends Activity {

    // {显示名, key, 类型(b/i/s/f), 默认值}
    private static final String[][] ITEMS = {
        {"语音输入",          "voice_input_enabled",            "b", "1"},
        {"会话搜索",          "conversation_search_enabled",    "b", "1"},
        {"深度思考按钮后缀",  "deep_think_button_suffix",       "s", ""},
        {"hCaptcha 验证",     "hcaptcha_enabled",               "b", "1"},
        {"流式平滑跟随",      "sse_smooth_follow",              "b", "1"},
        {"一键登录",          "one_tap_login_enabled",          "b", "1"},
        {"隐藏助手头像",      "hide_assistant_avatar",          "b", "0"},
        {"补全超时(ms)",      "completion_request_timeout_ms",  "i", "30000"},
        {"文件轮询间隔(ms)",  "query_files_time_interval",      "i", "1000"},
        {"PoW 预取数",        "pow_prefetch_count",             "i", "1"},
        {"会话预取数",        "session_prefetch_count",         "i", "1"},
        {"图片压缩格式",      "picture_compress_format",        "s", "webp"},
        {"客服中心地址",      "support_center_url",             "s", ""},
        {"普通上下文上限",    "normal_history_and_file_token_limit", "i", "0"},
        {"R1 上下文上限",     "r1_history_and_file_token_limit",     "i", "0"},
        // …可无限扩展，全部同构
    };

    private SharedPreferences sp; // == MMKV.defaultMMKV()

    @Override
    protected void onCreate(Bundle b) {
        super.onCreate(b);
        sp = MMKV.defaultMMKV();          // ← smali: MMKV;->k()

        LinearLayout root = new LinearLayout(this);
        root.setOrientation(LinearLayout.VERTICAL);
        root.setPadding(dp(16), dp(16), dp(16), dp(16));

        TextView title = new TextView(this);
        title.setText("灰度管理器");
        title.setTextSize(22);
        root.addView(title);

        TextView sub = new TextView(this);
        sub.setText("写入 kv_settings_* 覆盖服务端灰度 · 点 ↺ 恢复");
        sub.setTextSize(12);
        root.addView(sub);

        for (String[] it : ITEMS) addRow(root, it[0], it[1], it[2], it[3]);

        ScrollView sv = new ScrollView(this);
        sv.addView(root);
        setContentView(sv);
    }

    private void addRow(LinearLayout parent, String label, String key, String type, String def) {
        LinearLayout row = new LinearLayout(this);
        row.setOrientation(LinearLayout.HORIZONTAL);
        row.setPadding(0, dp(10), 0, dp(10));

        TextView tv = new TextView(this);
        tv.setText(label);
        tv.setLayoutParams(new LinearLayout.LayoutParams(0,
                ViewGroup.LayoutParams.WRAP_CONTENT, 1f));
        row.addView(tv);

        if ("b".equals(type)) {
            Switch sw = new Switch(this);
            sw.setChecked(sp.getBoolean(full(key), "1".equals(def)));
            sw.setOnCheckedChangeListener((v, on) -> put(full(key), on));
            row.addView(sw);
        } else {
            EditText et = new EditText(this);
            et.setInputType("i".equals(type)
                    ? InputType.TYPE_CLASS_NUMBER
                    : InputType.TYPE_CLASS_TEXT);
            et.setText(readAsString(full(key), def));
            et.setLayoutParams(new LinearLayout.LayoutParams(0,
                    ViewGroup.LayoutParams.WRAP_CONTENT, 1f));
            et.setOnFocusChangeListener((v, has) -> {
                if (!has) put(full(key), et.getText().toString());
            });
            row.addView(et);
        }

        Button reset = new Button(this);
        reset.setText("↺");
        reset.setOnClickListener(v -> {
            sp.edit().remove(full(key)).apply();   // 恢复服务端灰度值
            Toast.makeText(this, "已恢复灰度: " + key, Toast.LENGTH_SHORT).show();
            recreate();
        });
        row.addView(reset);

        parent.addView(row);
    }

    private static String full(String key) { return "kv_settings_" + key; }

    private String readAsString(String k, String def) {
        if (!sp.contains(k)) return def;
        try {
            return sp.getString(k, def);
        } catch (ClassCastException e) {
            return String.valueOf(sp.getAll().get(k));
        }
    }

    private void put(String k, String val) {
        // 注意：类型必须与业务读取端一致（decodeBool/decodeInt/decodeString）
        // 实际实现按 ITEMS 里声明的类型写入对应 putXxx
    }

    private int dp(int v) {
        return (int) (v * getResources().getDisplayMetrics().density + 0.5f);
    }
}
```

### 5.2 入口：GrayGesture（连点手势监听）

```java
package com.deepseek.chat.ga;

import android.content.Context;
import android.content.Intent;
import android.view.MotionEvent;
import android.view.View;
import android.widget.Toast;

public class GrayGesture implements View.OnTouchListener {

    private final Context ctx;
    private int count;
    private long last;

    public GrayGesture(Context c) { this.ctx = c; }

    @Override
    public boolean onTouch(View v, MotionEvent e) {
        if (e.getAction() == MotionEvent.ACTION_DOWN) {
            long now = System.currentTimeMillis();
            if (now - last > 600) count = 0;   // 间隔超时重新计数
            last = now;
            if (++count >= 7) {                // 连点 7 次解锁
                count = 0;
                ctx.startActivity(new Intent(ctx, GrayManagerActivity.class)
                        .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK));
                Toast.makeText(ctx, "灰度管理器已解锁", Toast.LENGTH_SHORT).show();
            }
        }
        return false;  // 一定返回 false，不能吞掉 Compose 的事件
    }
}
```

```smali
    invoke-virtual {p0}, Landroid/app/Activity;->getWindow()Landroid/view/Window;
```

## 六、生效路径与验证

1. App 启动 → 连点屏幕 7 次 → 弹出「灰度管理器」
2. 切换开关 → 写入 MMKV `kv_settings_<key>`（`SharedPreferences.apply()`）
3. **重启 App**（管理器内可加「重启」按钮）→ App 读取时 `kv_settings_*` 命中，覆盖灰度
4. 验证点举例：
   - `voice_input_enabled=1` → 输入框出现语音入口
   - `hide_assistant_avatar=1` → 助手头像消失
   - `sse_smooth_follow=0` → 流式输出不再平滑跟随
5. 点 `↺` → `remove(kv_settings_*)` → 回落到服务端灰度值

## 七、风险与取舍

| 风险 | 说明 | 对策 |
|---|---|---|
| MMKV 方法名混淆 | `decodeBool` 等被改成 `b/c/f` | 走 `SharedPreferences` 接口，不走混淆名 |
| 类型不匹配 | 用 putString 写 bool 会导致解码失败 | 按 `ITEMS` 声明类型写对应 `putXxx`；实施前逐项核对读取端 |
| MMKV 进程/实例 | 需与 App 同实例 | Activity 不设 `android:process`；一律用 `MMKV.defaultMMKV()` |
| 内存缓存不刷新 | App 运行中已缓存到 ConcurrentHashMap | 改完重启 App（管理器可加重启按钮） |
| Compose 设置页难注入 | 无法精确改"版本号"点击 | 用主 Activity 级连点手势替代（用户已同意二选一） |
| 新增类体积 | 手写 Smali 较长 | 逐行核对；先做最小可用版再扩展配置项 |
| 签名 | 重打包需签名 | `mt_apk_build sign=true` |
