## 一、结论（一句话）

`GmDialog` 的 `TYPES` 表里 **5 个键的类型是 2.4.5 时代的老类型**；
`GmStore.write` 按旧类型写（`putBoolean`/`putFloat`），而 2.5.1 的宿主按**新类型**读
（`MMKV.j`=String / `MMKV.g`=Int）⇒ **MMKV 类型不符 → 返回默认值 → 改动被静默丢弃**。

| 键 | 模块(2.9.6) | 宿主 2.5.1 | 后果 |
|---|---|---|---|
| `search_state_on_login` | `b` | **String**（`on`/`off`） | `putBoolean` → 宿主 `getString` 读到 null |
| `search_state_on_launch` | `b` | **String** | 同上 |
| `search_state_on_manually_created_chat` | `b` | **String** | 同上 |
| `search_state_on_automatically_created_chat` | `b` | **String** | 同上 |
| `sse_auto_scroll_smooth_stiffness` | `f` | **Int**（`Lf02;->V`=0x32=50） | `putFloat` → 宿主 `getInt` 读到默认值 |

> 与 2.9.4 修掉的 `volcengine_enabled`（b→s）**同一类错误**，只是这次是 4+1 个。

## 二、证据链（可复用的取证手法）

1. **读优先级没问题**：`Lo02;<init>` / `Lv77;<init>` 都是
   `mmkv.contains("kv_settings_<键>") ? 本地值 : (内存缓存 ? : kv_remote_settings_<键>)`
   ⇒ 本地覆盖优先 ✅（所以"写进去就一定生效"这个前提成立，问题只可能在**写入的类型**）。
2. **实例没问题**：`Lh02;<init>`（`q = MMKV.l()`）、`Lrv;<init>`（`a = MMKV.l()`）
   与模块 `GmStore.get()` 的 `MMKV.l()` **同一个实例** ✅。
3. **键名没问题**：宿主全部 70 个 `kv_settings_*` 字面量 vs 模块 70 个裸键 → **70/70 完全一致** ✅。
4. **类型就是问题**：
   - `Lo02;` 里 70 个键的读法是 `MMKV.c`(Bool) / `MMKV.g`(Int) / `MMKV.j`(String)，
     **`MMKV.e`(Float) 命中 0 次** ⇒ 2.5.1 的裸键里**没有 float 类型**。
   - `Lbka;`（聊天页真实消费点）读 `sse_auto_scroll_smooth_stiffness`：
     `contains → MMKV.g(String)I`，默认值 `Lf02;->V:I`，随后 `int-to-float` 给动画用
     ⇒ **宿主就是按 int 存的**。
   - `Lqa5;->D` / `Lo02;` 读 `search_state_on_login`：`MMKV.j(String)String`，
     默认 `Lf02;->M:String`；`Lf02` 里 `I/J/K/M = "keep"`、`L = "indeterminate"`。
   - **取值语义**（`Laea;->s(Lis9;String;String)V`）：
     ```java
     s = value.toLowerCase(ROOT);
     if (s.equals("on"))  → TRUE
     else if (s.equals("off")) → FALSE
     else → null            // 含 "keep" = 不覆盖 / 跟随服务端
     ```
     ⇒ 合法取值就是 **`on` / `off`**；下发实测（`ds_raw.txt` 第 142-143 行，2026-09-13 最新版）也是
     `search_state_on_launch {"id":19572873,"value":"on"}` ✅
   - **全量交叉验证**：拿真实下发数据（`ds_raw.txt`）逐键比对 JSON 值类型 vs 模块 `TYPES`
     → **只报出上面 4 个 search_state 键** ✅（+ 命中外那 1 个 float 键）
