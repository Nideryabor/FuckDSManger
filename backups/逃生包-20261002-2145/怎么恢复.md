## ⚠️ 特殊坑（务必读）

1. **`.l2s.*` 文件永远不要删** —— 沙箱存储层的 git 对象"真身"；`git fsck` 会误报 "garbage"。
2. **不要搬 `.git` 目录**；万不得已搬过 ⇒ `python3 tools/flatten_l2s.py` 平铺 + `git fsck` 体检。
3. **别用"直接拷 `.git` 目录"的方式做备份** —— 那些符号链接在 Android / 外部视角会报
   "Unable to open source file"（2026-10-02 主人遇到的正是这个）。**用 bundle 才是正道。**
4. `867d6cd` 之前历史完整；其后的 22 个提交曾被压平为 `48920a5`（明细见事故档）。
