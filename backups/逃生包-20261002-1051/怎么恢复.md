## 怎么恢复（在任何装了 git 的机器上）

```bash
git clone 小窝全历史.bundle 小窝
cd 小窝
git log --oneline | head          # 应该能看到 240 个提交
git remote add origin <你自己的私有仓库>   # 想推的话
```

**bundle 就是仓库本身**，不依赖任何网络、不依赖 GitHub。

## ⚠️ 本工作区的特殊坑（2026-10-02 事故换来的，务必读）

1. **沙箱存储层把 git 对象"真身"存成 `.l2s.*` 文件**（用软链以正常对象名暴露）；
   `git fsck` / `count-objects` 会把它们**误报为 "garbage"** —— **永远不要删 `.l2s.*`！**
2. **不要移动 `.git` 目录**。万不得已移动过 ⇒ 必须：
   `python3 tools/flatten_l2s.py /path/to/.git` 平铺 + `git show-ref` / `git fsck` 体检
3. `867d6cd` 之后 **22 个提交被压平**为 `48920a5`（明细见
   `专题/事故-2026-10-02-小窝git对象误删与重建.md` 与
   `backups/小窝-20261002-reflog-HEAD.txt`）。

| 东西 | 怎么补 |
|---|---|

**源码 + 脚本进了库，包和二进制随时能再造出来。**
