## 怎么恢复（在任何装了 git 的机器上）

```bash
git clone 小窝全历史.bundle 小窝
cd 小窝
git log --oneline | head        # 应该能看到 239 个提交
git remote add origin <你自己的私有仓库>   # 想推的话
```

**bundle 就是仓库本身**，不依赖任何网络、不依赖 GitHub。

## 注意：仓库是"可复现"的，但有几个大件没进去

这些是**故意不入库**的（`gitignore`），换机器要重下/重建：

| 东西 | 怎么补 |
|---|---|
| 底座 APK | `python3 mod-src/pack/patch_base.py`（脚本在库里，能重建） |
| `fdm-app/libs*/`（AAR/jar 缓存） | `python3 fdm-app/fetch_deps.py` |
| `tools/aapt2/` `tools/node/` `tools/jvm/lib/` | 见各自 README |
| 构建中间产物 | 跑一次 `sh 做包.sh <版本> <vc>` 就有 |

**⇒ 这就是这个项目一直坚持「脚本才留得住」的意义：**
**源码 + 脚本进了库，包和二进制随时能再造出来。**

## 建议

1. **把这个包抄到你的电脑 / NAS 上** —— 现在它和手机在同一条命上
2. **以后别往公开代码托管推了** —— 这个项目的性质（改商业 App）注定会被平台处理，
   账号被限一次之后，再开号重发通常会被当作规避，后果更重
3. 要版本管理的话，**自己机器上跑个私有的 Gitea/Forgejo**，或者就本地 git —— 
   反正你本来也是本地开发
