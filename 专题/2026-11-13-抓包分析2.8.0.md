## 二、★ 新端点验证：`/api/v0/chat/status` 确实存在

```
GET https://chat.deepseek.com/api/v0/chat/status   200
{"code":0,"data":{"biz_code":0,"biz_data":{
    "is_muted":0, "mute_until":null, "msg":null }}}
```

**2.7.5 全树没有 `chat/status` 这个字符串** ⇒ 确认是 2.8.0 新增。

### 2.1 ⚠️ 修正我之前的判断

我在 `2026-11-13-宿主2.8.0-新增了什么.md` 里把 `chat/status` 归到「额度」功能下 —— **错了**。
它返回的是 **`is_muted`（禁言状态）**，不是额度。

正确归属：
- **`/api/v0/chat/status` = 禁言/封禁状态查询**（发送前预检）
- 「额度」是另一套：`usage_limit_reached` 文案 + `QuotaAlert`/`QuotaTip` 页面

> `is_muted` / `mute_until` 这两个**字段名**在 2.7.5 里就有（`klb` / `zu1`），
> 2.8.0 新增的是**独立的查询端点**，不是新概念。

### 3.1 ★ 路径里带宿主证书 MD5

```
/api/initSecCdn/1/3b199b7a06468/com.deepseek.chat.a/e89b158e4bcf988ebd09eb83f5378e87
                                            ↑包名              ↑APK 证书 MD5
```

`e89b158e4bcf988ebd09eb83f5378e87` 就是宿主 APK 的证书 MD5（与 `mt_apk_open` 报的一致）。

⇒ **秒验会上报「包名 + 证书指纹」做应用校验**。
⇒ 我们用 Xposed（宿主 APK 一字节没改）⇒ **不受影响**。
⇒ 但如果哪天改成**重打包宿主**，这里立刻会咬人。

### 3.2 代码位置：`cn.fly.commons`

```
tmp/h280/cn/fly/commons/r.smali    ← 域名表全部在这里
    cfgc.zztfly.com / upc.zztfly.com / errc / devc / fdl / tgc / gd
```

| 项 | 2.7.5 | 2.8.0 |
|---|---|---|
| `cn/fly` 类数 | **505** | **505** |
| 类名差异 | — | **完全相同** |

⇒ **秒验 SDK 本身一个字节没变**，不是 2.8.0 新增。
（我上次分析「新增了什么」时只查了 `.kt` / 资源 / API 路径，**漏了这个域名族**。）

### 3.3 「未找到配置」说明什么

`initSec` / `initSecCdn` 都返回 `418 {"error":"未找到配置"}` ——
**秒验没有在 DeepSeek 后台开通**，SDK 挂了但服务端没配置。
⇒ 这条链路目前是**空转**，对我们无威胁。
