## 二、为什么改用「调用点」做判据

### 已失败的判据（**全部不要再用**）

| 版本 | 判据 | 失败原因 |
|---|---|---|
| 2.22.53 | 三槽白名单（谁先出现谁进槽） | 按钮/标题也可能进槽 ⇒ 被半透明 |
| 2.22.54 | 「第一个记录到的颜色」⇒ 全透明 | ❌ 认成了**消息页可点击对话标题按钮** |
| 2.22.55 | 「连续出现 ≥2 次」⇒ 背景 | ❌ 连续计数被"命中检查"挡在门外 ⇒ **实际失效** |
| 2.22.57 | 计数挪最前 + 用它分档 | ✅ 生效（`#0F0F0F` **37.93% → 22.36%**）但残留多 |
| 2.22.58 | 「曾是背景色」⇒ 全透明 | ❌ **一排同色按钮也被登记为背景色** |
| 2.22.59 | 「只认 `#0F0F0F` / `#FFFFFF`」 | ❌ `#0F0F0F` **满屏都是** ⇒ 一堆元素被透空（主人：「抽风」「又一堆东西透明了」） |

### 🔑 结论：**颜色这条路彻底走不通**

- 页面底色是「**层层嵌套**」（同一位置叠加）
- 一排按钮是「**横向并列**」（不同位置各一个）
- **但两者在 `uia.v` 的调用序列里都是"连续多次同色"** ⇒ **用颜色/连续性永远分不开**

### ✅ 新判据：**调用点 = 元素身份证**

```
页面底色  ⇒ 永远从 调用点 A 发出
按钮背景  ⇒ 永远从 调用点 B 发出
卡片底色  ⇒ 永远从 调用点 C 发出
```

**稳定 + 唯一 + 与颜色无关** ⇒ 正好解开"同色不同物"的死结。

## 二十三、🐛 真凶：`collect()` 的 NULL 解引用（2026-09-25 · `2.22.83`）

> 主人回执：整批日志 ＋「**一样的毛病，日志给你**」

### 证据链（一条 `why=7` 都没有）

### 真凶

```smali

if-eqz v0, :set_first          # ★ 列表为 null ⇒ 跳到 :set_first
…（去重 / 追加）
:set_first

```

**执行链**：① 第一次调用列表为 null ⇒ 跳 `:set_first` ② 对 **null** 调 `length()` ⇒ **NPE** ③ **被 `collect()` 自己的 `.catchall` 吞掉** ⇒ 静默返回 ④ **每次调用都重复** ⇒ **候选表永远是 null** ⑤ `onClick` 每次都走 `:empty_msg` ⇒ 吐司 =「**试验台：还没有候选——请先在目标页面划一下**」⑥ ⇒ **永远不会消融** ⇒ **"和上一轮一样的毛病"** ✅

> ⚠️ 这条 bug 是 **`2.22.80`** 引入的 ⇒ **两轮的"一样的毛病"是同一个原因**。
> ⚠️ 也说明：**主人看到的那个吐司，字面就是"还没有候选"** —— 我前两版都在错误的方向上找原因。

### 修复

```smali
sget-object v0, GmBubble->sAblateList
if-eqz v0, :set_direct          # ★ 为空 ⇒ 直接设（不再解引用 null！）
invoke {v0, p0}, contains → v1
if-nez v1, :ret                 # 已存在 ⇒ 返回
<append v0 + "|" + p0 → v0 ; sput>
goto :ret
:set_direct
sput-object p0, GmBubble->sAblateList        # ★ 之后所有 length()/contains() 都只在非空时执行
:ret
```

**顺带去掉 `0x600` 长度上限**（候选表本来只有十来条）。

| **按钮点了也不会变回去** | 没有学习 ⇒ 排除名单空 ⇒ 按钮照样被透明化 |

**⇒ 不是"判据不对"，是"链路没跑"** ⇒ **此时改参数全是白费**（教训 223）。

### 三条 `logOnce` 痕迹，一次照亮三个断点

| # | 断点 | 诊断行 |
|---|---|---|
| ① | `dispatchTouchEvent` 钩子有没有被调用 | `[触摸钩子] dispatchTouchEvent 钩子已被调用（说明触摸钩子生效）` |
| ② | `args[0]` 是不是 `MotionEvent`、`ACTION_DOWN` 到没到 | `[触摸] DOWN 收到 ACTION_DOWN（开窗）` |
| ③ | 采集链路的 `collect()` 有没有跑 | `[采集] collect() 已被调用（采集链路活着）` |

外加原有的 **`[交互排除] 学到 xxx`**（学习生效的证据）。

### 判读表（一眼定断点）

| 看到什么 | 断点在 | 下一步 |
|---|---|---|
| ①②③ 都有 + 有 `学到` | 链路全通 | 那"按钮没变回来"是另一类（按钮由别的锚点画）⇒ 发日志 |
| ①②③ 都有，**无 `学到`** | ③ 之后的判断（`sTouchOn`/`learn`） | 查 `sTouchOn` 读写 |
| **只有 ①**，无 ② | `args[0]` 不是 `MotionEvent` | 换入口取事件 |
| **① 都没有** | `dispatchTouchEvent` 钩子没被调用（宿主可能覆写） | 改钩更底层的入口（`ViewGroup.dispatchTouchEvent` / `View.onTouchEvent`） |
| **③ 都没有** | 采集链路没跑 | 查 `dg → collect` |
