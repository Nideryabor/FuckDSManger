# 专题 · 音频通话（🎧 实时语音对话）

> 立项：2026-09-19（主人需求）。首版：**NL 2.13.0**（`版本/2.13.0.md`）
> 一句话：**在 DeepSeek 里做一个「打电话给 AI」的页面** —— 持续听你说 → 宿主转文字 → 发给 AI → AI 回复由宿主朗读 → 循环。

---

## 一、主人原话（需求规格，别再走样）

1. 先把**上次那个 AI 按钮**改成 `wip`（＝「回复建议」页的【AI 生成】开关）。
2. **模块「聊天」选项里加一个音频通话功能**。
3. 在**包含「拍照 / 照片 / 文件」这三个按钮的同级处**放一个**音频通话按钮** ⇒ 点击跳转到通话界面。
4. 通话界面三个按钮：**挂断**（关闭当前页面）、**免提**（听筒 ↔ 免提切换）、**允许 AI 被打断**（启用灰度里的「打断并发」）。
5. 进入界面后**持续监听麦克风** → 取音频 → 走**宿主自己的音频转文字** → 作为**真实消息**发给 AI。
6. AI 生成完毕后，**自动调用宿主自己的文本转语音**播放出来。**以此循环**。
7. 「允许 AI 被打断」**手动开启时先弹「开发中」Toast**。

## 二、宿主地图（本轮实测，值得长期保留）

### 2.1 为什么「插进拍照/照片/文件那一排」不可行

```
UploadPanelActionButtonGroup (…uploadpanel/UploadPanelActionButtonGroup.kt:18)
  └─ UploadPanelActionButton (UploadPanelActionButton.kt:44 / :69)
        拍照 = 0x7f0f0373      照片 = 0x7f0f0372      文件 = 0x7f0f0375
        构造点 = Luk8;->m(Lwv3;Lsv3;Lhv3;Ley3;I)V
                 ↑ 三个回调是**三个独立参数**（枚举 Ljr9 的 a/c/b），不是列表
```

⇒ **三个按钮是 Compose 结构硬编码**，要在 smali 里「加第四项」等于手工改 Compose 树 ⇒ 采用**自绘悬浮钮**替代。

> 顺带：`Luk8;` 是个 R8 合并巨类（同时含大量 androidx/Compose 函数），**不要按类名推理**，按方法定位。

### 2.2 录音 → ASR（下一版的战场）

```
[麦克风按钮]  Lhc5;->g(...)  = VoiceInputButton (VoiceInputButton.kt:95)
               资源：voice_input_button = 0x7f0f037f      权限串：android.permission.RECORD_AUDIO
[录音器]      Lqra;   AudioRecord(16000, MONO, PCM16) + getMinBufferSize(0x3e80=16000)
               └ 读数据 La80;（AtomicReference<AudioRecord> 持有者）/ 回调 Lz70;（OnRecordPositionUpdateListener）
[ASR 服务]    WebSocket  /api/v0/asr/ws
               模型：com.deepseek.chat.network.chat.model.asr.*
                     AsrClientEvent.Cancel / Done、AsrEvent.BackendEvent、AsrBackendErrorCode
[语言]        MMKV key_preferred_asr_lang；UI = AsrLanguagePickerDialog / AsrLanguageSection
[错误文案]    asr_failed_toast / asr_connection_failed_toast / asr_interrupted_toast
```

⚠️ **坑**：`fragments` 那套 DB 上下文（2.12.x 主线）与 ASR **无关**；ASR 的 token 只在宿主内存里 ⇒ **不要试图自建 WebSocket**（老结论：自建 HTTP 要 token + PoW，成本极高）。

### 2.3 发送消息（真机验证过，2.10.14）

```java
Lyp1; input = new Lyp1();      // 输入框状态：字段 a=附件(hp8)、b=MutableState<bl2>
input.c("文字");                // 写文字
Lao1;->I(Lyp1;)V               // ⭐ 发送 ＝ 用户点发送按钮
```

`ao1` (= ChatSessionComponent) 靠 **hook `ao1.I` 捕获 `thisObject`** 拿到（`GmCallHook` 干这个）。

### 2.4 TTS（宿主自带，模块已有基建）

- 开关：MMKV `key_auto_tts_enabled`；下发字段 `model_configs.tts_feature.auto_tts_enable_by_default`
- 模块侧：**`GmTts.fix()` 会往下发 JSON 里补 `"tts_feature":{"auto_tts_enable_by_default":true}`** ⇒ 「AI 说完自动朗读」这一环**不用自己写**
- 端点：`/api/v0/chat/tts/`、`/v0/chat/tts/voice(s)`、`tts_ws`；时序键 7 个 `kv_[remote_]settings_tts_*`
- UI：`AssistantTtsButton` / `AutoTtsButton` / `TtsReadAloudViewModel`

### 2.5 打断并发（灰度）

- 键：**`interrupt_and_send_enabled`**（＝「发新消息会立即打断当前回复」），已在模块 `GmDialog` 的键表里
- 另有「AI 回复中也能直接发新消息（多流并发）」那一条（同族键，待核）

## 三、当前实现（NL 2.13.0）

| 类 | 职责 |
|---|---|
| `GmCallDialog` | 全屏深色通话页：标题 / **状态字** / **转录区** / 三按钮（挂断·免提·允许AI被打断）；`stat(String)`、`line(String)` 是线程安全更新入口；状态行**长按**＝`testSend()` |
| `GmCallRun` | `Runnable`，把 `(type,text)` 丢回 UI 线程写 TextView（`type 0=状态 1=转录`） |
| `GmCallBtn` | 聊天页 🎧 悬浮钮：挂 `decorView`（免悬浮窗权限）、可拖动（>20px 才算拖）、点开页面；默认位置「屏宽−68dp / 屏高×2/3」 |
| `GmCallHook` | hook `ao1.I` → 把 `thisObject` 存进 `GmCallDialog.sAo1`（发送入口） |

- 动作码：**0x39** 开通话页（`GmChatDialog` 菜单项也用它）/ **0x3a** 挂断 / **0x3b** 免提 / **0x3c** 允许AI被打断
- 悬挂浮钮时机：`GmResumeHook`（`MainActivity.onResume`）
- 免提：`AudioManager.setMode(MODE_IN_COMMUNICATION)` + `setSpeakerphoneOn(toggle)`；挂断时复位（`setSpeakerphoneOn(false)` + `setMode(NORMAL)`）
