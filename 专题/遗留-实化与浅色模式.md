## 十、⭐ 重大发现（2026-09-24 主人给的关键线索）—— **「半透明」的真身是 `pos` 档位**

### 主人的观察（三条全中）
> 1. 「**关掉背景显示，AI 气泡就不是透明的了**」
> 2. 「我怀疑：**哪怕是最新版，其实也是个蒙层 / 没真正透明底部**」
> 3. 「AI 气泡那个**透明度选项根本没用**」

### 铁证：`GmBg.ensure()` 里的 `addView`

```smali
    invoke-virtual {v6}, Landroid/view/Window;->getDecorView()   # 目标 = decorView
    ...
    invoke-static {p0}, GmBg->pos(Context)I
    move-result v8
    const/4 v9, 0x1
    if-ne v8, v9, :cond_e5
    const/4 v8, 0x0
    invoke-virtual {v6, v5, v8, v7}, ViewGroup;->addView(View;I;LayoutParams)V   # ★ index 0 = 最底
    goto :goto_ee
    :cond_e5
    if-eqz v8, :cond_eb
    invoke-virtual {v6, v5, v7}, ViewGroup;->addView(View;LayoutParams)V          # ★ 追加 = 最上
    goto :goto_ee
    :cond_eb
    invoke-virtual {v6, v5, v7}, ViewGroup;->addView(View;LayoutParams)V
    :goto_ee
```

| `pos` | 名称 | 真实行为 |
|---|---|---|
| **1** | **底图（在内容后面）** | **`decorView.addView(图, 0)` ⇒ 插到 index 0 = 真·最底层** ✅ |
| **2** | **混合（真背景）** | `addView(图)` **追加到最上层** ＋ `GmBgView.setBlend(1/2)` **图自己再与下面混合** ⚠️ |
| **0** | 蒙层 | 同 2（最上层） |

**⇒ 结论：`pos=2` 从设计上就是「图盖在所有内容上面 + 图自身半混合」—— 它是个会混合的蒙层，从来不是「底」。**
**⇒ 主人一直用 `pos=2`（日志每轮都写 `pos=2`）⇒ 现象与「蒙层」完全吻合。**

### 附带解释

| 现象 | 解释 |
|---|---|
| **关掉背景→气泡不透明** | 那层图不在上面盖着了 |
| **浅色模式发白** | `pos=2` 时 `GmBgView` 自带 `setBlend`（浅色下走 `MULTIPLY` 那套）⇒ 白底内容与图相乘 ⇒ 发白 |
| **透明度 100% 仍"半透明"** | 气泡底本身是 `se0.c=1.0`（不透明），半透明感**全部来自上层那张图** |

### `pos=1` 时还会发生什么（读 `GmBg.setBlend` 确认）

```smali
    sget v0, Build$VERSION->SDK_INT:I ; const/16 v1, 0x1d ; if-lt ... # 仅 Android 10+
    const v0, 0x1020002                      # android.R.id.content
    Activity->findViewById(I)View            # v0 = content
    ... isOn 且 pos==1 ...
    isNight ? BlendMode.SCREEN : BlendMode.MULTIPLY
    v0.setBlendMode(v1)                      # ★ 设在 content 上（而不是图）
```

⇒ **`pos=1` 时改的是「内容层」的混合模式**（白天 `MULTIPLY` / 夜间 `SCREEN`），
让**内容与底图自然融合** —— 这才是「真底图」该有的样子。
