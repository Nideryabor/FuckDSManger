## 四、当前判据体系（`GmBubblePaintHook.pg`）

```
① 方法名 == "v"          且 args[1] 是 Long          且 sDepth <= 0     ← 原守卫，一字未动
② 调用点 ∈ 排除名单(sSkipList)        ⇒ 什么都不做（return）   ★ 最优先
③ 调用点 ∈ 消融集合(sAblateCur)      ⇒ 置“非零全透明”并 return（试验台）
④ 调用点 ∈ 白名单（10 个）           ⇒ alpha=0x80（50% 半透）
⑤ sPageCnt <= 6（本页前 6 层兜底）   ⇒ 同 ④
```

## 七、雷区与约定（本阶段教训精选）

| 类别 | 铁律 |
|---|---|
| **方向类 bug** | 本项目已累计 **9 次** `if-*` 判反（含 2 次同型：`push` 的"超窗才重置"、试验台的索引回绕）。⇒ **写完必须做「边界值手算」**（把 `1` 和 `n+1` 代进去各走一遍） |
| **寄存器** | ① 用临时寄存器前**先问"它现在装着什么"**（`v3` 里装着 `args[1]`，别拿来当布尔）② 改完**必须验证**（`vercheck` / 全文检索 / 逐行读）③ **MT 的 `edit_check` 不做字节码校验**（`VerifyError` 只有真机才暴露） |
| **通道** | **自建小通道反复出问题 ⇒ 换公共通道**（私有缓冲 4 版残局 vs 模块日志一次通） |
| **观测** | **诊断上 UI（探针的字），不上日志**；**一条通道连续两版测不出变化 ⇒ 换通道** |
| **判据** | **同一元素有多个绘制来源**（加锚点要"按颜色把来源收全"）；**颜色锁不住，调用点才是身份证** |
| **"透"的前提** | **底下必须有内容**：alpha=0 是"删掉这层"，没图垫底就露黑底 |
| **实验** | 实验包要把结论变成**肉眼可判**（二值 vs 连续）；**用户说不清的审美 = 试验台给的样品** |
| **协作** | 机器给**候选清单**，人做**指认**（最快）；**用户回执里"重复出现的模式"信息量最大** |
