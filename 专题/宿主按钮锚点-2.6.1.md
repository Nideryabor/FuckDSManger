## 一、结果（13 锚点 + 画底原语）

见 TSV。要点：

- **R8 合并桶又变了**：2.6.1 里 `AppIconButton 家族 + InputModeToggleButton` 并进同一个类 **`l10`**；
  但它们的方法级指纹各自唯一 ⇒ **指纹法不受"桶怎么合并"影响**。
- **画底原语**：`uia.v(Lc76;JLmd8;)Lc76;` → **`qk7.D(Lx97;JLgn9;)Lx97;`**
  （三参：Modifier / long / Shape；与 `GmRemap` 表的 `uia→qk7, u/v→C/D` 一致；`C` 是 brush 版）。
- **"名字诈尸"**：旧锚点类名在 2.6.1 里全都"还在"、但已是别的类
  （uk8 剩 5 方法 / zc 5 / i52 2 / yb5 1 / a18 1 / zl9 3 / uia 31）⇒
  **只按类名找会假装成功**，必须核到方法形状。

## 三、下一位升级宿主时（照做即可）

```sh
# 1) 用 source-info 全树搜（先写 patterns.txt：13 条 "Xxx.kt:行" 或 "Xxx.kt"）
grep -r -F -f patterns.txt <新树>/ -l
# 2) 对命中文件逐条取「包含 const-string 的方法」
awk '/^\.method/{m=$0} /\.kt:/{if($0~/const-string/)print m" <<< "$0}' <新树>/xta.smali
# 3) 画底原语：找「3参·第2参long·第0参接口·返回第0参」的静态方法（全dex唯一）
# 4) 核验：python3 tools/check_glass_anchors.py <新树>
# 5) 改 GmGlassScope.BTN_ANCHORS + GmGlassSink.BG_CLS/BG_METHOD → 出包
```
