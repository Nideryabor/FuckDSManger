## 二、这一轮修掉的东西（含教训）

| # | 现象 | 真因 | 修法 |
|---|---|---|---|
| 1 | 灰度面板没值 / 值不全 | ① 键形错（模块内部自己补 `kv_remote_settings_` ✗）② MMKV 强类型（`getString` 对 int 返回默认 ✗）| 三种位置都试 + **哨兵默认值鉴型** ✅ |
| 2 | 点不开模块方法 | 那些方法是**包内可见**（模块 UI 和 `GmMmkvHook` 同包 ✗）⇒ `IllegalAccessError` | **反射 + setAccessible** ✅ + 按名匹配多重签名 ✅ |
| 3 | 一点动作就崩 | 我们 App 也注册了动作接收器 ⇒ 模块的 `GmUtil.log` 调 `XposedBridge`（我们进程没有 ✗）| 动作**只在宿主进程**执行 ✅（双保险守卫 ✅） |
| 4 | 点了像"没反应" | 值在子 composable 里**现读** ⇒ Compose 认为"没变"跳过重组 ✗ | 值必须由**观察了状态的那层**传下去 ✅ |
| 5 | 返回要按两次 | 导航状态是枚举（页内跳页时没变 ✗）⇒ 不重画 + 每次点击塞一条栈 | 导航状态改成**页面 id** ✅ |
| 6 | 输入框打不进字 / 存不上 | ① 每敲一个字都被宿主回执盖回 ✗ ② 初值**晚到**时 `remember` 不重算 | 编辑中不跟宿主 ✅ + 没动过就跟随 ✅ + 失焦/离开提交 ✅ |
| 7 | 选图到不了宿主 | SAF 的 URI 是**第三方 provider** 的 ✗ ⇒ 跨进程授权无效 | 原图写**公共中转目录** `/sdcard/Pictures/FDM/` ✅ + 告诉宿主路径 ✅ + 宿主用模块自己的 `saveImage` 写进内部目录 ✅ |
| 8 | 界面日志看不见 | ColorOS 吞掉应用进程的 `android.util.Log` ✗ | **借宿主打点**（`ui_step`）✅ |
| 9 | 构建"看着成功其实是旧的" | tee 吞了退出码 ✗ / dex 旧 ✗ | `set +e` 显式报错 ✅ + **⑥ dex 新鲜度** ✅ |
| 10 | 装上去一开就崩（早期） | 清单相对名 + 改包名 ✗ / kotlin-stdlib 没进 dex ✗ | 一律**全限定名** ✅ + 依赖闭包补全 ✅ + ⑨⑩⑪ 三道自检 ✅ |
