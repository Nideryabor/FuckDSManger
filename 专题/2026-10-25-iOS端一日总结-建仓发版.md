```objc
// FDMConfig.m —— enabledFor 只看自己的 enabled，不走父链
- (BOOL)enabledFor:(NSString *)gid {
```

## 二、`ui_auto_shot`：没有眼睛的时候，自己造一只

### 为什么

这一轮设备上：MCP 8090 全关、无 frida（27042 也关）、
`/var/jb/usr/bin` 里 `snaputil` 只是 APFS 快照工具、**没有任何命令行截屏**。

⇒ 改完 UI，电脑这头完全看不见结果。

### 做法

设置页必须在 App **自己进程内**打开，才能在进程内 `drawViewHierarchy`。
所以让模块自己来：18s 弹设置页 → 每 3s 深进一个子页 → 各拍一张 → 自己 dismiss。

### 踩的坑

| 坑 | 病根 | 修法 |
|---|---|---|
| 四张图全是首页 | `static __weak nav`，present 完成前被 ARC 释放 | 强持有，`End()` 置 nil |
| 页尾字段拍不到 | 设置页比一屏长 | 新增 `FDMUIAutoShotCaptureTail()` 滚到底补拍 `*-tail.png` |

### 主人的要求（重要）

> 「做成开关，默认关，不然会有隐私泄露嫌疑」

于是上了四道闸：

1. 变成「调试 → 📸 自动截图」真开关，字段默认 `NO`
2. **先关再干活**（`setValueQuietly:NO` 在排程之前）⇒ 崩了也不会下次再弹
3. 每轮开跑前清掉上一轮 `fdm-ui-*.png`
4. 新增「🗑 清空截图」按钮

顺带修了两个自己挖的坑：

- `setValue:` 会记 `__mod` ⇒ 自动关回会让开关挂 ⭐、首页显示「已改 1 项」，
  可用户什么都没改 ⇒ 新增 `FDMConfig -setValueQuietly:for:key:`
- `FDMUIAutoShotBegin` 原来**先赋值后判空** ⇒ 有模态时 nav 存了却永不 present，
  后续 Push 往不在屏幕上的 nav 里塞 VC，`rc=0` 看着成功其实拍的是宿主界面

## 三、安全：从「哪来的」到「不漏」

### 口令来源（主人要求查清）

**不是猜的、不是推的。** 它从 iOS 端第一天（10-16）就硬编码在 4 个脚本里，
10-17 那晚「口令搬家」收进 `.env`。**逐字节比对：与旧硬编码完全相同。**

| 检查 | 结果 |
|---|---|
| git 历史 | **0 次**（`git log --all -S` 零命中） |
| 第二份 `.env` | 无，只有 3 个 `.env.bak` |
| shell 历史 | 无 |
| 还散落在哪 | ⚠️ `backups/pre-env-fix/` 4 个文件明文（已脱敏） |

### 修的两个真隐患

**A. 远端 argv 泄漏（高危）**

```bash
# 旧
"cat > /tmp/_s.sh && echo '$PW' | sudo -S -p '' sh /tmp/_s.sh"
```

`$PW` 在本地展开后拼进**发到设备的命令串** ⇒ 执行那一两秒，
设备上任何能跑 `ps` 的进程（含宿主 App）都能看到明文。

**新写法：两步走，口令只走 stdin**

```bash
sshsu() {
    local tmp="/tmp/_fdm_$$.sh"
    printf '%s\n' "$1" | sshpass -e ssh $SSH_OPTS "$USER@$HOST" "cat > $tmp"
    printf '%s\n' "$PW" | sshpass -e ssh $SSH_OPTS "$USER@$HOST" \
        "sudo -S -p '' sh $tmp; rm -f $tmp"
}
```

> 没用「口令+脚本挤同一条 stdin」的省事写法 —— `sudo -S` 可能多读，
> 会吞掉脚本第一行。多 200ms 换确定性。

**B. 本机 argv 泄漏** —— `_env.sh` 加 `export SSHPASS`，
全部 `sshpass -p` → `sshpass -e`（8 个脚本已核对都有 source）。

### 实测证据（不是"应该没事"）

在设备上高频轮询 `ps`，同时连跑两次部署：

```
抓到的行数: 10047
里面有没有口令明文: 0
```

抓到的命令行：`zsh -c sudo -S -p '' sh /tmp/_fdm_410.sh;` —— 只有路径。

### 护栏：`tests/security/test_secrets.sh`（21 项）

| 组 | 查什么 |
|---|---|
| ① | 无 `echo $PW \| sudo` |
| ② | 无 `sshpass -p`，统一 `-e` |
| ②b | 用了 `-e` 必须 `source _env.sh` |
| ③ | 除 `.env*` 外全项目 0 处明文 |
| ④ | `.env` 权限 600 + gitignore |
| ⑤ | git 侧四条：已跟踪 / 暂存区 / 全历史 / ignore 命中 |
| ⑥ | 真实容器 UUID 与用户 UUID 不进 docs/README/VERSION/tools/src |
| ⑦ | data 类目录必须被 ignore |

⑥⑦ 的值是**运行时从 `.env` 和 `iphone/*.db` 现取**，换设备自动跟着变。

**自证**：故意塞回 `sshpass -p` → 立刻报红；塞真 UUID 进 docs → 立刻报红。
护栏不是摆设。

### 特殊处理：`打包带走.sh` 不动

原想给它加 `--exclude=.env`，主人一句话点醒：

> 「别纠结这个 sh，本来就拿来给我小窝全备份的」

**全备份就该包含 `.env`** —— 排除掉的话恢复出来连 SSH 都连不上，备份作废。
已完整还原。

### 推送路径（撞墙记）

| 尝试 | 结果 |
|---|---|
| HTTPS `git push` | ❌ `GnuTLS recv error (-110)`，所有 IP 的 443 TLS 层都不通 |
| 改 `/etc/hosts` 换 IP | ❌ 四个 IP 全试，无效 |
| `api.github.com` | ✅ 200（独立路径） |
| **`ssh.github.com:443`** | ✅ **通** ⇒ 走 SSH over 443 |

方案：用 `api.github.com` 加 deploy key → `~/.ssh/config` 把 github.com
指向 `ssh.github.com:443` → `git push` 正常。**以后不用 token**。

## 五、富文本根治（v80 核心）

### 症状

```
13:19:32  [ensure] ★ 巡检修正 … 325→265 字     ← 只修一次
（之后永远沉默，屏幕一直裸着）
```

### 病根

v78 巡检的指纹记的是**原串**：

```objc
if (prev && [prev isEqualToString:str]) continue;   // 当前 == 原串 ⇒ 以为修过了
[gEnsuredFP setObject:str forKey:v];                // 记的也是原串
```

宿主把渲染结果**打回原样** → 当前串又变回原串 → 巡检永远放手。

**我叫它「状态驱动」，可比的根本不是状态，是我的记忆。**

### 修法

```objc
[gEnsuredFP setObject:rich.string forKey:v];        // 记「结果串」
if (prev && [prev isEqualToString:str]) continue;   // 当前 == 结果 ⇒ 才对
```

加上：
- 去掉「含 `<` 才处理」的误判闸门（渲染后可能仍含 `<`）
- 渲染器说无事可做时也记账（省 CPU）
- 防抖：同控件 1.5s 内最多 6 次

### 真机证据（关键就是「反复修」）

```
13:33:37  修正 144→123
13:33:41  修正 144→123   ← 又被打回，又修
13:33:42  修正 144→123   ← 再打回，再修
累计 15 次
```

> 遗留：仍是「打地鼠」（宿主持续打回，我们持续修）。真正根治要在宿主绘制层，
> 成本极高。当前策略保证不出裸标签，先这样。

## 六、AI 点歌（v80 新增）

### 体检结论

渲染 / 播放 / 去重 / 三处快速闸**全都齐**。
唯独**没有任何东西告诉模型这个标记存在** ⇒ 模型永不写 ⇒ 功能等于不存在。

### 修法：拼进系统提示词

新增 `FDMDjPromptFragment()`，拼在 `FDMInjectConfig()` 返回文本末尾 ——
**零新增通道、零新增 hook**，走原有 `⟦FDM⟧ … ⟦/FDM⟧` 链路（显示层由 `FDMStrip` 抹掉）。

三个新开关：`dj_prompt_on`（默认开）/ `dj_prompt_text`（可自定义）/ `dj_inline_hint`。

### 措辞上的坑

| 坑 | 处理 |
|---|---|
| 模型爱写「正在为你播放《晴天》⟦DJ:…⟧」 | 明写「这行除了标记什么都不要写」「不需要解释」 |
| 我在 UI 说明里用了 markdown 加粗 | iOS 不渲染 → 显示字面星号 ⇒ 全项目 16 处 `**` 清掉 |
| 半角/全角冒号 | `⟦DJ:` 必须半角 U+003A，已用 python 逐字节核对 11 处 |

### 端到端实锤

```
13:33:42  [dj] 红色高跟鞋-蔡健雅 15 秒内处理过，跳过   ← 去重生效
13:34:17  [dj] ♪ 红色高跟鞋 - 蔡健雅 已开播          ← AI 真的点了
```

提示词注入 → 模型写标记 → 渲染层解析 → 搜索播放 → 去重。**全链打通。**

### 撤设备旧版

