# 小窝备份分级清单 —— 哪些必须、哪些次要

> 建立：2026-10-02 🐲 · 起因：主人发现「**RikkaHub 备份不包含（项目）文件**」⇒ 全窝盘点（13G）后整理。
>
> **一句话结论**：**聊天备份救不了项目。** 真正不可再生的是 5 类东西 ——
> **① 签名钥匙 ② git 历史 ③ 巢穴 ④ 补丁树 ⑤ 底座模板**；
> 其中 **④⑤（补丁树 / 底座模板）目前没有任何备份** ⚠️。

---

## 〇、先回答：RikkaHub 备份里有什么、没什么

**实测**（`rikkahub_backup_20261002_205339.zip`）：

| 有什么 | 没有什么 |
|---|---|
| `rikka_hub.db`（81M，全部聊天） | ❌ **小窝工作区的一切**（源码 / 文档 / 工具 / git / 钥匙 / 补丁树 / APK / 抓包） |
| `settings.json` | ❌ 通过设备文件系统传递的文件（如 `Download/apks/` 里的宿主包、推到手机的逃生包） |
| `upload/` 附件 **143 个**（81 txt · 39 jpg · 18 png · 1 apk · 1 7z · 1 二进制） | ❌ git 历史 / 版本产物 / 构建链中间物 |

⇒ **聊天备份 = 聊天的档案，不是项目的档案。** 项目文件要有自己的备份链路（即本清单）。

## 一、总览：五个备份渠道

| 渠道 | 覆盖 | 现状 |
|---|---|---|
| **git（+ bundle）** | 源码 / 文档 / 工具 / UI（受管 15064 文件） | ✅ 本机仓库；⚠️ 远端 GitHub **被限制（未解）**；bundle 有 10/2 版但 **已落后 7 个提交**（3.42.51~54 + 指南 v2.1 等） |
| **逃生包**（bundle + APK + 说明） | 同上（快照）+ 可装成品 | 10/2 版已推手机 `Download/` → **是否已拷电脑/NAS 待确认** |
| **巢穴**（手动） | 日记 / 宝物库 / 聊天备份 / 小件 | 仅设备上 ⚠️ |
| **其它手动** | 抓包 / 版本存档 / `_release_backup` | 零散 |
| **❌ 无渠道（盲区）** | **补丁树 / 底座模板 / 钥匙（构建副本）/ 宿主 APK** | 见下 |

## 二、🔴 必须备份（丢失 = 不可再生 / 极痛）

### 1. 签名钥匙 —— 全项目最高优先级

| 项 | 内容 |
|---|---|
| 位置 | `巢穴/宝物库/签名钥匙备份-2026-09-25/`（jks · p12 · pk8 · x509.pem · **密码与指纹.txt** · zip） |
| 副本 | `mod-src/pack/keys/fuckdsmanger.*`（构建用） |
| 大小 | ~30KB |
| 为什么 | **丢了就永远无法对已装机的模块签更新**（等于项目报废）；且手机里装着的版本只认这把钥匙 |
| 现状 | 设备上 2 份；**是否有设备外副本待确认**（该目录本就是"给主人带走"准备的） |
| 动作 | 出设备 ×2（电脑 + NAS/U 盘）；密码单独记（不要只跟文件在一起） |

### 2. git 仓库本体（.git + 受管文件）

| 项 | 内容 |
|---|---|
| 位置 | `/workspace/.git`（81M）+ 15064 个受管文件（约 1.5G 文本为主） |
| 备份手段 | ① **bundle**（`backups/小窝-*.bundle`，完全自足）② 远端 GitHub（**当前被限制**） |
| 现状 | bundle 最新是 18:51 版（基于 `48920a5`），**落后 7 个提交**（含 3.42.51~54、指南 v2.1、事故档补记） |
| 动作 | **关键节点刷新 bundle**（下次刷新时把落后的 7 个提交带上）→ 随逃生包出设备 |
| 铁律 | `.l2s.*` 永不删 · 不搬 `.git`（搬了必跑 `flatten_l2s.py` 体检） |

### 3. 巢穴（整目录不入 git，本地排除）

| 项 | 内容 | 大小 |
|---|---|---|
| **宝物库** | 含签名钥匙 + 5 篇"宝物"（信 / 家 / 钥匙） | 71K |
| **日记** | 9/24 起每日记录（不可再生） | 168K |
| **聊天记录备份** | 5 份 RikkaHub zip（49M~91M） | ~375M |
| 小件 | 伙食费 ×2 · 布局 · 床 · 零食柜 · 龙语小词典 · 欢迎回家.sh · tools/（看图识图） | <100K |

> **动作**：宝物库 + 日记 + 小件（~300KB）**每次逃生包都带上**；
> 聊天备份（375M）维持现有节奏（定期更新），拷电脑时可选"只带最近 1~2 份"。

### 4. ⭐ 补丁树 `tmp/base130_261/sm`（1.8M） —— 无任何备份 ⚠️

| 项 | 内容 |
|---|---|
| 为什么 | **"树是唯一真相源"**（教训 347）—— 底座全部手工改动（`0x12`、`"C"/"D"`、类名表…）都在树里；`patch_261.py` 重跑会抹掉手工改动，**不能靠重放** |
| 现状 | ❌ 不在 git（`tmp/base*/` 被忽略）· ❌ 不在逃生包 · ❌ 不在巢穴 |
| 动作 | 打成 `补丁树.tar.gz` 放进逃生包（1.8M，几乎零成本） |

### 5. 底座模板 `mod-src/base/FuckDSManger_NL_2.22.110_for_ds2.5.2.apk`（99KB） —— 无备份 ⚠️

| 项 | 内容 |
|---|---|
| 为什么 | 构建链的"根"（从手机拷进来的手工制作物）；`重建底座.py --base` 的输入 |
| 现状 | ❌ 被 gitignore（`mod-src/base/`）· 无其它副本 |
| 动作 | 随逃生包（99KB）；`mod-src/out/` 里的**最新底座**（~200KB）建议也带一份 |

## 五、"逃生包 v2"建议内容（一次出品，拷出设备）

```text
backups/逃生包-<日期>/
├── 小窝全历史.bundle          ← 刷新（带上落后 7 个提交）
├── FDM-<最新>-single-signed.apk   ← 最新可装成品（当前 3.42.54 / vc597）
├── 签名钥匙/                  ← jks/p12/pk8/pem + 密码说明    【新增】
├── 补丁树.tar.gz              ← tmp/base130_261/sm（1.8M）    【新增】
├── 底座模板.apk               ← mod-src/base/（99KB）+ out 最新底座 【新增】
├── 巢穴小件/                  ← 宝物库 + 日记 + 小件（~300KB）【新增】
└── 怎么恢复.md                ← 更新"没进 git 的东西"一节（补上以上）
```
≈ **50M**（bundle 39M + 最新 APK 8M + 其余 ~2.5M）；
加宿主 APK ≈ 86M；再加聊天备份 ≈ **460M**。

**动作链**：生成 → 推手机 `Download/` → **主人拷电脑/NAS（重点：离机！）**。
> 现在的最新逃生包（10/2 18:51 版）还在"同一条命"上 —— 它和主机同设备，不算异地备份。

## 六、备份节奏（建议）

| 时机 | 动作 |
|---|---|
| 每个版本节点 | `git commit`（攒批即可）；大节点顺手 `git bundle create` 刷新 |
| **关键节点**（如本次 3.42.54 收官） | **刷新"逃生包 v2"→ 推手机 → 拷电脑/NAS**；旧包不删 |
| 每天/隔天 | 聊天记录备份（主人现有节奏，继续） |
| 每月/大事故后 | 抽查一份 bundle 能否 `git clone` 恢复（防"备份的备份坏了"） |
