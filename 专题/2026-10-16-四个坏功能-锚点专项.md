### ✅ 破解办法（**仍然是静态**，不是 frida）：把 2.6.2 的 APK 放进我的小窝

我现在走的是 **MT MCP 通道**，只能一条一条搜 —— 慢且无法跑工具链。
如果把 `deepseek (2)clone.apk` **放进小窝**（`/workspace/`），我就能：

```sh
# ① 三个 dex 全反编译
baksmali d 2.6.2.apk/classes.dex  -o tmp/h262 ; baksmali d .../classes2.dex -o tmp/h262 ; ...
# ② 工具链一次跑完（指南 §2 的标准姿势）
python3 tools/fp_match.py  tmp/h261 tmp/h262 --file 锚点清单.txt   # 类级重定位
python3 tools/fp_method.py tmp/h261 tmp/h262 <类>                  # 成员名对照表 ← 关键！
python3 tools/gray_check.py tmp/h262 tmp/base130_261/sm            # 灰度全量逐键
python3 tools/check_glass_anchors.py tmp/h262                      # 玻璃/按钮锚点
```

⇒ **`fp_method.py` 会直接吐出「成员名对照表」**，`pr6.o → qn7.x`、`qk7.C → qn7.Y` 这种一次全解决。
⇒ 全程**只读、不改代码、不碰手机**，完全符合当前约束。
