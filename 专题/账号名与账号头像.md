# 美化 › 隐藏账号名 / 修改账号头像

> 2026-09-13 · 尼得亚伯 🐲 ｜ 版本：**2.9.8**（versionCode 95）
> 一句话：侧边栏（对话列表抽屉）底部那行「账号名 + 账号头像」，现在可以隐藏名字、替换头像。

---

## 一、位置是怎么定下来的（逆向路径）

宿主 DeepSeek **2.5.1** 全量 R8 混淆，但 Kotlin 会往 dex 里塞**源码位置字符串**，这是最好的路标。

1. 搜 dex 字符串 `drawer` → 命中 `com.deepseek.chat.ui.components.drawer.*` 与
   `com.deepseek.chat.ui.pages.chat.views.ChatNavigationDrawerContent (ChatNavigationDrawerContent.kt:145)`
   ⇒ 侧边栏内容就在 `ChatNavigationDrawerContent.kt`。
2. 在宿主里搜「打码手机号」的字面量 `"****"` → 只有 2 处，都是
   `Llx8;->t0(IILjava/lang/String;Ljava/lang/String;)`（≈ `StringBuilder.append(seq,start,end)`）
   ⇒ 这就是手机号打码：
   ```
   if (mobile.length != 11) { log("MobileUtil", "mobileNumber.length should be 11"); null }
   else mobile.substring(0,3) + "****" + mobile.substring(7,11)   // 158****8888
   ```
   旁边还带着 `Lu9a;->Y("MobileUtil")` 的 trace —— 函数名本身就叫 **MobileUtil**。
3. 顺着 `Ls5;->v()`（上面两处打码之一所在的方法）反查：它是**合成 lambda 类**，
   `public final synthetic a:I` 就是 switch 分派下标。全库搜它的构造点，传 `0x8` 的只有一个：
   `Leb1;->h(Lld6;Lc76;Ley3;I)V` 里的 `new-instance Ls5; const/16 v11, 0x8`。
4. `Leb1;->h` 的 trace 字符串写着
   **`com.deepseek.chat.ui.pages.chat.views.UserInfoFooter (ChatNavigationDrawerContent.kt:632)`**
   ⇒ 这就是侧边栏底部那一行。

## 二、`UserInfoFooter` 里有什么

| 元素 | 落点 |
|---|---|
| 账号名（`Text`） | 取值自 `Ls5`(a=8) 的 state，最终由 `Lz89;->b(String;…)` 绘制 |
| 账号头像 | `Ljt5;->N(…)` 取 URL 图；取不到时退到 `painterResource(0x7f07010f)` → `Lme4;->a(...)`（Icon） |
| 右侧小图标 | `0x7f0700bf` = `ic_ellipsis`，contentDescription = `0x7f0f02da` = `settings` |

### 账号名取值逻辑（`Ls5;->v()` 的 `a == 8` 分支）

```
1) id_profiles 里选中的 profile 有昵称 → 用它
2) 否则 Lgy.a() 非空                  → 用打码手机号 158****8888
3) 否则                              → 兜底字符串 sider_profile = "My Profile"
```

（`Lgy` = 账号模型，由 `com.deepseek.chat.account.model.KVAppUserInfo` 反混淆而来）

### 账号模型（`Lh45;` = `KVAppUserInfo`，序列化器 `Lf45;`）

`token` / `id` / `email` / `mobile_number` / `status` / `chat_status` / `id_profiles` /
`need_birthday` / `is_mainland` / `minor_mode_status`

> ⭐ **模型里没有头像字段** ⇒ 头像只能走资源替换这条路（见 3.2）。

## 三、实现（2.9.8）

### 3.1 隐藏账号名

hook **`Ls5;->v()`**：先读 `this.a`（int），只有 `== 8` 才 `setResult("")`。

- ✅ **全库唯一**：`Ls5;-><init>(Object,Object,Object,I)` 的调用点里，传 `0x8` 的**只有** `UserInfoFooter`
- ✅ 只影响侧边栏底部这一处，不动设置页
- ⚠️ 返回的是**空串**（不是 null）：Compose 的 `Text("")` 不显示内容，行仍在（头像 / 点击区不受影响）

### 3.2 修改账号头像

与「修改助手图片」同一套路：hook **`Resources.getDrawable`**，命中资源
**`0x7f07010f`（`ic_profile`）** 时返回自定义图片。

| 项 | 值 |
|---|---|
| 落盘文件 | `fuckds_uavatar.png`（app 私有 `filesDir`） |
| 开关键 | `fuckds_gm` / `uavatar_on` |
| 选图 | `GET_CONTENT` + `startActivityForResult(0x4359)` → `GmPickHook` 新增的第三分支落盘 |

### 3.3 美化页新增的两个条目

```
美化
 ├── [●] 修改助手图片（WIP）   ← 本次补上 WIP 标记（已知 bug：蓝色方块）
 │    [选择图片]
 ├── [●] 隐藏账号名            ← 新增
 ├── [●] 修改账号头像          ← 新增
 │    [选择账号头像]
 ├── 文件快捷选项 ›

```

UI 由新类 `GmBeautyAdd.sw()/btn()` 生成，避免继续撑大 `GmBeautyDialog.open()` 的寄存器预算。

## 四、坑 / 待验证

| # | 事项 |
|---|---|
| 1 | **Icon tint**：默认头像由 `Lme4;->a(...)`（Icon）绘制，若宿主施加 tint，实机可能显示成**纯色块**——与「修改助手图片」的蓝色方块疑似**同源**，真机一测即知 |
| 2 | `ic_profile` 若在别处复用（设置页 / 其它图标），会**一并被替换** |
| 3 | 账号若已从第三方（微信 / Google）带过头像 URL，则走 URL 分支，本条 hook 不生效 |
| 4 | 两个 hook 都依赖宿主 2.5.1 的混淆名（`Ls5` / `0x7f07010f`），**宿主升级必须重新定位** |

## 五、教训

- **第 55 条：Kotlin 合成 lambda 的 `public final synthetic a:I` 就是 switch 下标**，可以当「反查唯一构造点」的钥匙 ——
  先找到逻辑所在的方法 → 读出下标 → 全库搜 `new-instance` + 该下标，就能精确锁定**唯一调用点**。
- **第 56 条：`"****"` 是最省事的定位锚点**。想找「打码手机号」不要猜混淆类名，
  直接在 dex 字符串里搜这个字面量，再顺 `StringBuilder.append(seq,int,int)` 的调用点即可。
- **第 57 条：非 range 的 `invoke-*` 最多 5 个寄存器**。六参方法（如 `GmBeautyAdd.sw()`）必须用
  `invoke-static/range {v0 .. v5}`，且**参数寄存器必须连续升序** ——
  所以要把 listener 先塞进 `v5`、bool 塞进 `v4`，不能按习惯的 `{act, parent, title, sub, bool, listener}` 顺序写。
