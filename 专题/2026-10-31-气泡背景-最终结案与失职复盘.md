## 六、给下一次的我

1. **有 frida 就先用 frida。** 不要用打包装机做迭代。
2. **改一个类之前先看它多大。** 超过基线 +15% 就说明你堆了太多东西。
3. **`if-*` 写之前先写一遍真值表**（本文附录）。
4. **底座和做包永远不许并行**（守门已有锁）。
5. **看到"功能起来了"先问：是谁给的？** 用 git diff / 逐项回退去确认，不要假设。
6. **一个版本只改一处**，且**改完立刻用运行时验证**，不要靠猜。
7. **不确定就说不确定**，不要用"应该可以"糊过去。

## 附录：if-* 真值表

| 指令 | v 与 0 比较（`*-z`） | 双寄存器比较 |
|---|---|---|
| `if-eqz` / `if-eq` | == 0 则跳 | 相等则跳 |
| `if-nez` / `if-ne` | != 0 则跳 | 不等则跳 |
| `if-ltz` / `if-lt` | < 0 则跳 | 小于则跳 |
| `if-gez` / `if-ge` | >= 0 则跳 | 大于等于则跳 |
| `if-gtz` / `if-gt` | > 0 则跳 | 大于则跳 |
| `if-lez` / `if-le` | <= 0 则跳 | 小于等于则跳 |

⚠️ 单寄存器 vs 0 **只能用 `if-*z`**；写 `if-gt v, :x` 会汇编报错。
⚠️ 写"放行/跳过"前先看标签在**上面还是下面** —— 往回跳 = 死循环。
