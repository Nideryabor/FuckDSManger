## 美化 `GmBeautyDialog`

| 修改助手图片 | 开启后可自定义 AI 回复旁的头像 | 开关 |

## 对我们 Compose UI 的要求

1. **层级与文案照抄**（包括那句说明文字，别自己改写）
2. **顺序照抄**
3. 首页 → 菜单 → 各功能页 → 子页（气泡/背景/招呼语/文件快捷/数据库/日志）
4. 「过检」= 环境伪装、「调试」= DIAG/元素捕获器（首页与菜单里是同一个东西的两个入口）
5. 原 UI 用「动作型」条目（选择图片、换身份、清空、复制、恢复默认）—— Compose 版也要有对应动作
