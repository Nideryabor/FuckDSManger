## 二、**共同的画底原语**（整个功能的地基）

```
Luia;->v(Lc76;JLmd8;)Lc76;
          ↑     ↑   ↑
      Modifier  ARGB  Shape
```

= 宿主的 `Modifier.background(色, 形状)` 包装。

**证据**：三个按钮类都在调它 ——

| 出处 | 调用点（`mt_apk_search(target=smali, query="Luia;->v(")`） |
|---|---|
| `Luk8;`（AppButton） | `.line 608` 一条 |
| `Lzc;`（AppIconButton） | `.line 159` · `.line 1417` 共两条 |
| `Lqo2;`（AppTextButton） | `.line 143` · `.line 209` 共两条 |
| `Lpn9;`（消息项） | `.line 182` ← **我们模块早就钩过它**（气泡用的就是同一条） |
| `Lzl9;` · `Lax3;` · `Ldm0;` · `Lxo6;` … | 卡片/背景等一堆 |

⇒ **同一个原语，按钮和卡片都在用** ⇒ 我们 3.29.0 必须加**按钮作用域计数器**
（`GmGlassScope`，hook 上表里那 4 个 composable 的方法边界），否则整个界面都会变玻璃。

## 三、Compose 内部 API 的可达性（决定能不能拿坐标）

| API | 混淆了没 | 依据 |
|---|---|---|
| `androidx.compose.ui.platform.AndroidComposeView.getSemanticsOwner()` | **✅ 没混淆**（名字原样在 dex） | `dex_names` 搜 `Semantics` 只命中 2 条，且类名是完整的 `Landroidx/compose/ui/platform/AndroidComposeView;` |
| `SemanticsOwner` / `SemanticsNode` / `SemanticsConfiguration` 的方法 | ❌ 混淆（如 `Lms6;->getSemanticsOwner()Ln68;`） | `dex_names` 搜 `SemanticsNode` / `BoundsIn` **0 命中** |
| `DrawScope` / `DrawContext` / `Modifier` / `Element` | ❌ 混淆（`Lc76;` = Modifier） | 全库搜不到原名 |

**结论**：**能按名字拿到的只有 `getSemanticsOwner`**；其余一律走**结构定位**
（参数个数 + 返回类型 + 是不是接口）。

⇒ 于是 3.29.0 的两条主线是：

1. **按钮作用域**：按混淆名 `uk8.a/b/c` + `zc.c/d/h/l` 直接 hook（锚点，跟底座那 51 条同类）；
2. **画布劫持**：从 `uia.v` 的**第 0 个形参类型**拿到 `Modifier` 的 Class（名字都不用知道），
   在其上找「两个参数」的方法 = `foldIn`，用 `Proxy` 造一个假 `Function2` ⇒ 掏出链上每个
   **元素**的 Class ⇒ 那个类里「1 参 + 返回 void」的方法就是 `draw(DrawScope)` ⇒ 挂它。

`getSemanticsOwner` 这条路**暂时没用上**（v2 拿按钮矩形时才会用），但已经确认可行。

## 四、升级后怎么重定位（checklist）

> ✅ **已照此重定位过一次（宿主 2.6.1，2026-10-02）** —— 结果与核验脚本：
> `专题/宿主按钮锚点-2.6.1.md` · `参考/数据/host_2.6.1-按钮锚点.tsv` · `tools/check_glass_anchors.py`

1. `mt_apk_search(target=dex_string_members, query="AppButton.kt")` ⇒ 拿到 AppButton 族的方法签名；
   同理换 `AppIconButton.kt` / `AppTextButton.kt`。
2. `mt_apk_search(target=smali, query="Luia;->v(")`，**但先把 `Luia;` 换掉** ——
   找「三个参数、第 2 个是 long、第 0 个是接口、返回同第 0 个」的静态方法（整个 dex 扫一遍，
   命中最多的那个就是画底原语）。
3. 更新 `GmGlassScope.BTN_ANCHORS` 与 `GmGlassSink.BG_CLS/BG_METHOD`。
4. 跑 `做包.sh`，装，看日志里的
   `【GmGlass】按钮作用域钩子 N 条` / `【GmGlass】发现元素类 …` / `【GmGlass】换掉绘制 #N`。
