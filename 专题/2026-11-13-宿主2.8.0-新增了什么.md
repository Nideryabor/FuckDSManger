# 宿主 2.8.0 新版本新增了什么（差分报告）

> 2026-11-13 · 尼得亚伯 🐲 · 2.7.5（vc295）→ 2.8.0（vc297）
> 方法：`.kt` 源文件差分 + 资源表差分 + API 路径差分 + 常量差分 + 组件/权限/.so 差分

---

## 〇、一句话结论

**2.8.0 只加了两件事：① 导出全部历史对话 ② 额度（quota）提示与告警。**
除此之外：权限 0 变化、native 库 0 变化、AB 键 0 变化、数美 0 变化、检测面 0 变化。

## 二、新功能 B：额度（Quota）提示与告警

### 2.1 新源文件（另外 2 个）

```
QuotaAlert.kt   ← 聊天页弹窗（com.deepseek.chat.ui.pages.chat.QuotaAlert）
QuotaTip.kt     ← 输入框上方提示条（...session.input.QuotaTip）
```

### 2.2 新增 1 个字符串 + 1 段额度错误文案

| 资源名 | 中文 |
|---|---|
| `usage_limit_reached` | **使用额度已达上限，请额度恢复后再试** |
| `edit_quota_exceed_toast`（旧有） | 修改输入次数超过限制 |
| `regenerate_quota_exceed_toast`（旧有） | 重新生成次数超过限制 |

### 2.3 新增 1 个 API

```
GET /api/v0/chat/status     ← 查当前额度状态（tz0:2066）
```

### 2.4 ★ 新增 1 个 SSE 流内事件：`quota_info`

聊天流（SSE）里新增一种事件，用来在对话中途下发额度：
```
g37:  const-string "quota_info"  →  Lqgc;->D(Ltn;Ljava/lang/String;)V  →  e(String) 塞内容
kc5:  "quota_info" 放进 singletonMap 交给 Compose
```

### 2.5 新增的额度数据结构字段

```
quotas                     额度数组（可能多类额度）
is_exhausted               是否已耗尽
reset_at                   额度重置时间
quota_exceeded_message     超限提示文案（服务端可下发）
usage_limit_reached        已达上限
key_quota_alert_show_keys  ★ 本地 MMKV 键：记录"哪些告警已弹过"
user_closed                用户主动关闭（埋点）
```

> `key_quota_alert_show_keys` 说明**弹窗有「只弹一次」的抑制逻辑**（存 MMKV）。

## 四、★ 对我们（FDM）的影响评估

### 4.1 好消息：**没有任何破坏性变化**

| 我们依赖的东西 | 状态 |
|---|---|
| 设置行路由桶 `z5 → y5` 的 packed-switch | **59 项 / 29 case / 标签名全同** ✅ |
| 账号头像桶 `b6 → a6` 的 packed-switch | 29 项，只差标签地址 ✅ |
| AB 灰度键（172 / 86 / 73 / 198） | **全部相等** ✅ |
| 数美反检测 27 方法 | **逐条指令相同** ✅ |
| MMKV 读写落点 `tj7.h → sl7.h` | 方法名没变，304 行，sim 0.997 ✅ |

> 关键：**新功能都在「设置 → 数据控制」二级页**，没有往主设置列表加行，
> 所以那个最容易被新功能打乱的下标桶（`e=22/23` 那套）**没动**。

### 4.2 新功能给模块留的空白（可选做）

| 机会 | 落点 | 难度 |
|---|---|---|
| **接管额度显示** | SSE 事件 `quota_info`（`g37` 里 `qgc.D`）→ 可以伪造额度，或把 `QuotaAlert` / `QuotaTip` 藏掉 | 中（SSE 流内事件，要在解析层拦）|
| **去掉额度弹窗** | `QuotaAlert` / `key_quota_alert_show_keys` | 低（抑制键写死就永不弹）|
| **接管导出** | `exportHistory()`（`jc5`）→ 可以拦、可以改下载链接 | 低 |
| **改额度文案** | `usage_limit_reached`（0x7f0f03dd）| 低（`GmResTextHook` 现成）|

### 4.3 提醒：`usage_limit_reached` 出现在 3 个类

```
av1   f27   g21
```
如果要做文案替换，这 3 处都要覆盖（`GmResTextHook` 是按资源 id 换的，一处就够）。

## 五、和 2.7.5 的版本历史对照（一眼看规模）

| 版本 | 新增 .kt | 新增 string | 新增 API | 新增类 |
|---|---|---|---|---|
| 2.7.5 → **2.8.0** | **3** | **9** | **3** | 66（全库）|

`2.8.0` 是一次**功能性小版本**：两个 C 端功能（导出 / 额度），没有架构改动，
没有新权限，没有新 native 库，没有新反检测。
