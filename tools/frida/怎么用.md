# Frida 怎么开 · 白话版（v2：什么都不用拷）

一句话：**手机上跑一条命令，把 frida-server 开起来。然后我就能秒级改代码。**

---

## 你要做的 —— 就一条命令

手机的终端里（MT 管理器终端 / Termux / 随便什么终端）：

```sh
su -c 'sh /data/data/me.rerere.rikkahub/files/workspaces/*/files/tools/frida/frida-device.sh all'
```

**看到这行就是成功：**

```
[frida] ✓ 起来了 · 127.0.0.1:27042
```

> 为什么不用拷文件：我的工作区**本来就在你手机上**，
> 上面那条路径直接指过去就行。脚本会**从自己旁边**找 frida-server 二进制。

---

## 如果它说"没起来"

多半会看到这句：

```
failed to create file "/data/local/tmp/frida-helper-xxx.dex": Permission denied
```

**补跑一条，再重来：**

```sh
su -c 'chmod 777 /data/local/tmp'
su -c 'sh /data/data/me.rerere.rikkahub/files/workspaces/*/files/tools/frida/frida-device.sh start'
```

---

## 以后日常就记这两条

```sh
su -c 'sh /data/data/me.rerere.rikkahub/files/workspaces/*/files/tools/frida/frida-device.sh start'   # 开
su -c 'sh /data/data/me.rerere.rikkahub/files/workspaces/*/files/tools/frida/frida-device.sh stop'    # 关
```

（嫌长就在手机上存个别名，或者直接把脚本 `cp` 到 `/sdcard/frida.sh` 再跑也行）

<details>
<summary>附：这脚本到底干了啥（不想看可以跳过）</summary>

1. 把 `frida-server` 复制进 `/data/adb/`
2. 给它执行权限
3. 建个空目录 `/data/adb/frida-tmp` 当"草稿纸"
4. 让它在后台跑，监听 `127.0.0.1:27042`

**为什么不用大家常用的 `/data/local/tmp`？**
你这台手机的 root 是**只读**的 —— 那目录连 root 都写不进去（我实测 `touch`/`chmod`/`mount` 全被拒）。
所以换成 `/data/adb`，并把 frida 的"草稿纸"也一起挪过去，绕开限制。

**为什么我这边不用 adb 转发？**
工作区是跑在手机上的，跟手机**共用同一个 127.0.0.1** ——
（证据：我在工作区里 `curl 127.0.0.1:8787` 能直接打通 MT 管理器那个 MCP。）
所以 frida-server 一在 `127.0.0.1:27042` 上听着，我直接连。
</details>
