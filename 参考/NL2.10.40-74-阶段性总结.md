## 一、三条主线

### 主线 A：崩因闭环（2.10.47 ~ 2.10.51）

| 项 | 结论 |
|---|---|
| 真堆栈 | `Resources$NotFoundException: String resource ID #0x7f0f0221` |
| 链路 | `yb5.c` → `pd5.H(g56)` → `vc5.d0` → `Resources.getString(g56.d)` |
| 根因 1 | 末端列表接管有**两个** hook 点（`GmSuggestHook`/args[1]、`GmSuggestHook2`/args[0]），此前**只停了一个** ⇒ 越界 id 一直在写（`d = 0x7f0f021f + i`，而 `0x7f0f0221` 宿主资源表里不存在） |
| 根因 2 | `GmPromptTextHook.idxOf()` 是**退化废码**（`if-ne p0,p0` 恒假 ⇒ 永返回 -1）⇒ 文案接管从未生效 |
| 修法 | 造对象时 **`d=null`**（永不触发 `getString`）+ `pd5.H` 上 `setResult` 决定文字 + `idxOf` 严谨化 |

**⇒ 结果：不再崩，chip 文字由模块决定。**

### 主线 B：模型切换被服务器下发顶掉（2.10.52 ~ 2.10.67）★ 最曲折

| 阶段 | 版本 | 关键发现 |
|---|---|---|
| 误以为"写入无效" | 52~56 | `GmModel.reapply` 只读写**模块侧快照**，从不碰宿主 |
| 打出证据 | 57~59 | **命中 4 次、成功 0 次**；`VerifyError`（static 方法参数应 `p0`，我写了 `p1`） |
| 结构化改写 | 60 | `replace` → **JSON 解析**（`GmModel.fix`）⇒ 一发即中 |
| 排除 A/B | 62 | **写入后回读 = true** ⇒ 落盘没问题，是"被覆盖" |
| 用户实验定音 | 63 | **断网启动 ⇒ 卡常显** ⇒ 覆盖源 = 服务器下发 |
| 首次摘除失败 | 64~65 | ① 寄存器被 `move-result-object v0` 覆盖 ⇒ 代码静默没执行；② `remove` 抛异常 ⇒ Map **不可变** |
| 同型副本 | 66~67 | 塞 `HashMap` ⇒ `argument 1 has type bx4` 崩 ⇒ **用 `orig.getClass()` 造同型副本** ✅ **成功** |

**⇒ 结果：`switchable` 与 `prompt_feature` 都不再被下发覆盖。**

## 三、关键教训（本轮沉淀，编号沿用项目教训表）

| # | 教训 |
|---|---|
| **307~313** | **日志文案要能"认版本"**；**关键证据要提前无条件打**；**崩溃捕手是基础设施** |
| **318~320** | **同一函数被读/写两路调用时日志必须分标**；**对抗服务端覆盖只能在"它写完之后"动手**；**结构化改写解决格式差异顽疾** |
| **321~330** | **"写成功"必须用"读回来"验证**；**缓存型配置：事后写盘徒劳**；**去掉干扰项比改造它简单**；**改别人的 Map 要防不可变** |
| **331~334** | **插桩前必须核对"此刻该寄存器装的是什么"**；**Xposed 内异常默认被吞**（"没报错"≠"执行了"）；**要打真正的关键路径** |
| **338~341** | **替换 Xposed 参数必须保持"宿主声明的具体类型"**；**"同型副本"是最稳造法**（`orig.getClass()`，不写死混淆名）；**不可变常与具体类型绑定** |
| **342~344** | **同一个 bug 会以不同面貌反复出现**（`switchable` 与 `prompt_feature` 都是"精确字符串替换"）；**"操作成功"是假象** |
| **345~347** | **"保存"和"保住"是两件事**（每个可被覆盖的设置都要有 `reapply` 挂在生命周期/下发点上）；**老线遗留 `reapply` 要逐个体检** |
| **351~353** | **用户的反例比自己的推理可靠**；**同一 UI 有两条数据链路时先确认哪条真的通**；**不要轻易停用"已验证可用"的东西** |
| **354~356** | **hook 参数不要写死下标**（扫描 + `instanceof`）；**"类型不匹配"已出现三次** ⇒ 回写 `param.args` 前必须判类型 |
| **360~362** | **"对齐"问题＝没照抄同类项结构**；**改容器变量后后续引用都要跟着改**；**改完 UI 要读回自检** |
