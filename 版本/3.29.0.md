## 二、宿主侧实现（一句话）

> 钩住宿主**画按钮底色的那一处**，把实心底**换成玻璃底**：

```
GmGlassScope   按钮作用域计数（hook AppButton / AppIconButton / AppTextButton 的方法边界）
GmGlassSink     hook 画底原语 Luia;->v → 结构定位出「背景元素」类 → 劫它的 draw(DrawScope)
                在 DrawScope 里：drawIntoCanvas → nativeCanvas → 画玻璃
GmGlassBackdrop PixelCopy 抄窗口 surface（1/4 降采样）→ GmGlassBlur 糊掉 → 缓存（限流 220ms）
GmGlassBlur     StackBlur（逐字节照抄参照物）
GmGlassAtoms    从 DrawScope 的变换矩阵反推窗口坐标（拿不到就退 0,0）
GmGlassCfg      读 fuckds_glass_*（走 GmStore.read2）
GmGlassInstall  安装 + 钩 Activity.onResume + 配置刷新
```

**玻璃三层**：① 糊过的底图（折射感）→ ② 浓度蒙层 → ③ 高光边 + 水滴柔光。

### 为什么这样画（关键决策）

- 在按钮上**盖一个 View** ⇒ 按钮的**文字/图标会被糊掉**。
- 所以不插 View，而是**劫宿主自己的绘制**，让玻璃**垫在文字下面**。
- 劫 `draw(DrawScope)` 而不是「换一个 Modifier」：要自己 `new` 一个 Compose 的
  `Modifier.Element` / `DrawModifier` 就得 `implements` **混淆接口** —— 编译期写不出来。
  劫 `draw` 只要一个 `Class` + 方法名，运行时结构定位就能拿到。

### 为什么全程反射、不写死类名

宿主把 Compose 全混淆了（`Lc76;` = Modifier）。3.29.0 的策略：

| 环节 | 定位方式 |
|---|---|
| 画底原语 | 锚点 `uia->v`（和底座那 51 条 hook 同性质） |
| `Modifier` 接口 Class | **从被钩方法的第 0 个形参类型拿** —— 名字都不用知道 |
| 背景元素类 | `foldIn`（**两个参数**的方法）+ `Proxy` 假 `Function2` ⇒ 让 Compose 自己把元素喂过来 |
| `draw` 方法 | 那个类里「**1 个参数 + 返回 void**」的方法 |
| 原生画布 | `drawIntoCanvas`（1 个参数 + void）→ 参数里找「**0 参、返回 `android.graphics.Canvas`**」的方法 |
| DrawScope 尺寸 | 「0 参、返回 long」的 getter（Compose 的 `Size` 是 inline class，擦成 long） |

**一个混淆名字都没写死**（除了两处锚点，且都在 `专题/宿主按钮锚点-2.5.2.md` 里记了重定位方法）。

## 四、⚠️ 待真机验证（这一版最大的未知）

**必须看日志确认的 3 行**（都在 `【GmGlass】` 前缀下）：

| 日志 | 说明 | 没有的话 |
|---|---|---|
| `按钮作用域钩子 N 条` | 期望 **7**（uk8.a/b/c + zc.c/d/h/l） | 宿主改版 ⇒ 按 `专题/宿主按钮锚点-2.5.2.md` 重定位 |
| `发现元素类 …` | 期望 1~3 个类 | `foldIn` 没找到（参数个数变了）⇒ 换成「0 参返回对象」扫描 |
| `换掉绘制 #N` | 按钮出现时才刷 | 作用域没进去 ⇒ 检查按钮锚点 |

另外要肉眼确认的：

1. **开玻璃后，按钮的文字/图标还在不在**（在 = 绘制顺序对了 ← 这是本版设计的核心赌注）；
2. **非按钮的卡片/气泡有没有被误伤**（有 = `GmGlassScope` 深度算错了）；
3. **卡不卡**（`PixelCopy` 是每 220ms 最多一次 + 1/4 降采样 + 960×2160 图约 130 万像素，
   三趟盒式模糊约 4×130 万次加法 —— 应该 <10ms，但**真机为准**）；
4. **关掉开关能不能完全复原**（`GmGlassCfg.on()==false` ⇒ `beforeHookedMethod` 直接 return ⇒ 原绘制照常）。

**已知限制**（写在这里免得当成 bug）：

- **没有真折射**：v1 是「糊底 + 浓度 + 高光边 + 水滴」。AGSL `RuntimeShader` 折射要 **API 33+**，
  宿主 minSdk 23 ⇒ 得按版本分支，留 v2。
- **坐标反推可能不准**：`GmGlassAtoms` 走 `drawContext → transform → currentTransform → values()`，
  宿主版本若改了 Compose 内部结构就退 0,0 ⇒ **底图会贴错位置**。兜底表现是「糊的位置不对」，
  不会崩。真机看到明显错位 ⇒ 告诉我，我改成「语义树取矩形」那条路（可行性已核实）。
- **模糊度是 px 不是 dp**：`fuckds_glass_blur` 直接当 StackBlur 半径用（再 /4 因为降采样）。
  真机觉得不够糊就调大。
