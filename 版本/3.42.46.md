## 一、改了什么（就一处，在我们自己的类里）

**静态定死的事实**：宿主 `ob7.i` 会**逐片**绘制，并在每片之后执行

```java
m.setTranslate(x, -p.b());   // ★ 是"整个替换"，不是叠加
sh.setLocalMatrix(m);        // ⇒ 我们在 b(J) 里算好的"铺满矩阵"被抹掉
```

⇒ 所以 3.42.43~45 那几版无论怎么调缩放公式，**矩阵都活不过一次绘制循环**。

### 改动

| 文件 | 改动 |
|---|---|
| `GmBmpShader` | 新增字段 `m0:Matrix`、方法 `baseMatrix(Matrix)`；**override `setLocalMatrix(Matrix)`** —— 宿主来设矩阵时不再照单全收，而是**合成 `M0 ∘ T`**（采样 = M0(p + T)）：保住我们的缩放/居中，同时跟随宿主的逐片平移 |
| `GmBubbleFitHook` | 造完 shader 后用 `baseMatrix(ourMatrix)` 代替 `Shader.setLocalMatrix(ourMatrix)` |

安全阀：`m0` 未设或宿主传 null ⇒ **原样直通**（保持老行为，绝不更差）。
