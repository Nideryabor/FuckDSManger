# FuckDSManger NL 2.10.68（📝 修「文件快捷选项」保存不生效：`patch()` 也栽在精确字符串上）

> 产物：`FuckDSManger_NL_2.10.68_for_ds2.5.2.apk`（**219 / NL 2.10.68**，91 类，V1+V2+V3，sha256(partial) `48815ebc…`）
> 触发：主人 —— 「同理顺便修掉文件快捷回复的问题」→ 确认指「**文件快捷选项编辑保存后不生效**」

---

## 一、根因：和 `switchable` 一模一样的坑

`GmPrompt.patch(src, ours)` 原来是**精确字符串替换**：

```java
NEEDLE = "\"prompt_feature\":[";        // ← 无空格！实际 JSON 只要有空格就匹配不上
找 NEEDLE → 再往后找【第一个 ']'】收尾   // ← 数组里若有 ']' 还会截错
```

**⇒ 匹配不上时它原样返回**；而 `apply()` 里**即使没有改动也会 `hostPut` 写回**：

```java
String v3 = patch(v2, v0);   // 没改动 == 原样
hostPut(v3);                 // 照样写回 ⇒ 磁盘上什么都没变
return true;                 // ⇒ toast「已保存」
```

**⇒ 于是出现「保存成功、内容没变」** —— 和当初 `switchable` 的病症完全同源：**该用解析器的地方用了字符串**。

---

## 二、本版：`patch()` 改用 JSON 结构化改写

```java
if (src == null || ours == null || ours.isEmpty()) return src;

JSONArray arr    = new JSONArray(src);       // 模型配置数组
JSONArray ourArr = new JSONArray(ours);      // 用户编辑的那份 prompt_feature
boolean changed = false;
for (int i = 0; i < arr.length(); i++) {
    JSONObject o = arr.optJSONObject(i);
    if (o == null) continue;
    if (!o.has("prompt_feature")) continue;
    o.put("prompt_feature", ourArr);         // ★ 直接换掉整段
    changed = true;
}
if (changed) return arr.toString();
return src;                                   // 任何异常/无改动 ⇒ 原样返回（不破坏数据）
```

**⇒ 只要那份 JSON 里有 `prompt_feature` 字段，无论空格、换行、转义、嵌套如何，都能精确改掉。**

## 四、这对"回复建议"意味着什么

`prompt_feature` 这条链现在**三处都通了**：

| 环节 | 状态 |
|---|---|
| 编辑器读到宿主真值 | ✅ 2.10.52（`host()` 走 native 本体） |
| 保存写进宿主 | ✅ 2.10.52（`hostPut()`） |
| **改写逻辑正确** | ✅ **2.10.68（JSON 结构化）** |
| 不被服务器下发覆盖 | ✅ 2.10.67（`model_configs` 整项摘掉） |

**⇒ 下一步若要做「回复建议」，可以参考同样的三段式**：读真值 → 结构化改写 → 防下发覆盖。

## 五、教训

| # | 教训 |
|---|---|
| **342** | ⭐⭐⭐ **同一个 bug 会以不同面貌反复出现**：`switchable`（60 版）和 `prompt_feature`（68 版）**都是"精确字符串替换"** 惹的祸 ⇒ 项目里凡涉及 JSON 改字段，一律走解析器 |
| **343** | ⭐⭐⭐ **"操作成功"的假象**：`apply()` 无论如何都写回 ⇒ 界面上"保存成功"从来不能证明"内容变了" ⇒ **写回前应先判断"有没有改动"**（本版已让 `patch` 无改动时原样返回，可据此加提示） |
| **344** | ⭐⭐ **修改型 API 要"无改动可识别"**：返回原串 / null / bool 三选一，让调用方能区分"改成功"和"没改到" |
