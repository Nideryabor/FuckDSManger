2.10.34 的字段 dump **直接输出裸字符串**：

```
FuckDSManger: c:java.lang.String= | d:java.lang.Integer=null | a:int=9 | b:… ｜ …
```

⇒ 它**不含「字段」二字**，主人按关键字搜当然找不到（我这边也忘了给前缀）😅

## 二、本版

```smali
    "[建议] g56 字段 → " + <dump内容>
```

⇒ 现在日志里会出现一行 **`[建议] g56 字段 → …`**，搜「字段」即可定位。

```
1. 覆盖安装 FuckDSManger_2.10.35_for_ds2.5.2.apk（vc186）→ ★ 强停宿主 → 重开
2. 进会话 → 传图（别发送）

```
