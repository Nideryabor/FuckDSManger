## 一、① 隐藏「美化 → 文件快捷选项」

`GmBeautyDialog` 里那一项（标题「文件快捷选项 ›」+ 副标题 + `GmClick(0x11)`）：

**⇒ 在它的 `setOnClickListener` 之后加一行**：调用新增的 `GmBeautyDialog.hideItem(view)`

```java
static void hideItem(View v) {          // 新增方法
    try { v.setVisibility(View.GONE); } catch (Throwable t) { }
}
```

**⇒ 该项容器直接 `GONE`** ⇒ 界面上不再出现（比删代码安全、也不影响其它项布局）。

## 二、② 「聊天」菜单新增「回复建议 ›」

`GmChatDialog`（模块的「聊天」二级菜单，原本有「防撤回」「模型切换」两项）按**同样的结构**加了第三项：

| 元素 | 内容 |
|---|---|
| 标题 | **「回复建议 ›」** |
| 副标题 | 「输入框上方显示一排可点击的回复建议，点一下直接发送（数量/文字可自定义）」 |
| 点击 | `GmClick(0x33)` |

**`0x33` 是现成的** —— `GmClick.onClick` 的分发链里已经有：

```smali
:cond_196
const/16 v1, 0x33
if-ne v0, v1, :cond_19e
invoke-static {}, …GmSuggestDialog;->open()V     ← 直接复用，无需新增分发
```

**⇒ 所以点击后进入的是「回复建议」设置页**（`GmSuggestDialog`：总开关 / 显示数量 / 模板池（每行一条） / 保存 / 恢复默认）。

> 顺带确认：`GmClick` 的分发链当前已排到 `0x37`（`GmSuggestDialog` 的 open/save/reset/close/toggle 都在其中），所以**不需要新号段**。
