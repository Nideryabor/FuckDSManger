## 二、宿主侧情报（本轮新挖，写清免得重查）

### 2.1 🔴 「拍照 / 照片 / 文件」那排**不能插第四项**（重要结论）

```
上传面板 = com.deepseek.chat.ui.pages.chat.session.uploadpanel.UploadPanelActionButtonGroup (…Group.kt:18)
  └─ UploadPanelActionButton (…ActionButton.kt:44 / :69)
       拍照 = resource 0x7f0f0373     照片 = 0x7f0f0372     文件 = 0x7f0f0375
       构造点 = Luk8;->m(Lwv3;Lsv3;Lhv3;Ley3;I)V   ← 三个回调各是一个**参数**（枚举 Ljr9 的 a/c/b）
```

- **三个按钮是 Compose 结构写死的**（三个独立 lambda 参数），**不是数据驱动列表** ⇒ 在 smali 层「往里加第四项」＝给 Compose 树插节点，基本不可行。
- ⇒ 主人选了 **方案 B：模块自绘悬浮钮**（不碰宿主 UI）。位置默认「屏宽 − 68dp，屏高 2/3」，**可拖动**（拖动位移 > 20px 才算拖、否则算点击）。

### 2.2 宿主的「录音 → ASR」链路（已定位，下一版接）

| 角色 | 类/证据 |
|---|---|
| 麦克风按钮 | `Lhc5;->g(...)` = `…input.voice.VoiceInputButton (VoiceInputButton.kt:95)`，文案资源 `voice_input_button` = 0x7f0f037f |
| 输入区提示 | `chat_input_placeholder_voice` = 0x7f0f007e，用在 `Llx0;->j(...)` |
| 录音本体 | `Lqra;`：`AudioRecord(16000, 单声道, PCM16)` + `getMinBufferSize` + `startRecording`，读字节的是 `La80;`（`AtomicReference<AudioRecord>` 持有点）、`Lz70;` 是 `OnRecordPositionUpdateListener` |
| ASR 服务 | URL `/api/v0/asr/ws`（WebSocket）；模型类 `…network.chat.model.asr.*`（`AsrClientEvent.Cancel/Done`、`AsrEvent.BackendEvent`、`AsrBackendErrorCode`） |
| 语言设置 | MMKV 键 `key_preferred_asr_lang`（还有 `AsrLanguagePickerDialog`） |
| 错误文案 | `asr_failed_toast` / `asr_connection_failed_toast` / `asr_interrupted_toast` |

> ⚠️ **宿主混淆极重**：`Lqra;`/`Lhc5;`/`Luk8;`/`Lch;` 等是 **R8 垂直合并**出来的巨类（一个 .class 里塞了录音器 + MenuBuilder + TypefaceCompatUtil …）⇒ **别按「一个类一个职责」推理**，要按**方法**定位。

| 模块已有能力 | **`GmTts.fix()` 会给下发 JSON 里补 `"tts_feature":{"auto_tts_enable_by_default":true}`** ⇒ 「AI 说完自动朗读」这一环**本来就有基建** |

### 2.4 发送链路（已真机验证，本版重新接上）

```java
yp1 input = new yp1();        // 输入框状态（Lyp1;-><init>()V）
input.c("要发送的文字");       // Lyp1;->c(Ljava/lang/String;)V
ao1.I(input);                 // ⭐ 发送（Lao1;->I(Lyp1;)V）＝ 用户点发送按钮
```

`Lyp1;` 只有 `a:Lhp8`（附件）+ `b:Lnv6`（`MutableState<bl2>`）两个字段，`c()` 写文字、`b()` 读文字。

## 六、教训（本轮）

| # | 教训 |
|---|---|
| **491** | ⭐⭐⭐ **Compose 写死的 UI 不能「插一项」**：先看它是不是**数据驱动列表**（传参/枚举）、还是**结构写死**（多个 lambda 参数）。是后者就别硬啃，直接换「自绘浮层」——省下的是好几版。 |
| **492** | ⭐⭐ **R8 垂直合并会把不相干的类塞进同一个 `.class`**（本轮 `Lqra;` 里同时有录音器和 MenuBuilder）⇒ **按方法/字段定位，不要按类名推理职责**。 |
| **493** | ⭐⭐ **资源名是最好的路标**：`voice_input_button`(0x7f0f037f)、`upload_panel_camera`(0x7f0f0373) 一搜即得 + `resource_xref` 直达构造点，比搜中文串快得多（宿主的中文串**不在 dex 字符串表**里，只在 resources）。 |
| **494** | ⭐ **`if-eqz`=等于0跳、`if-nez`=不等于0跳**（本轮写 `GmCallBtn.onTouch` 分发链时连踩两处：`getAction` 用错了参数寄存器 + 判跳方向反了；`show()` 里 `getWindow()==null` 也写反）⇒ **守卫语句写完立刻回读一遍**（老教训，仍然犯）。 |
