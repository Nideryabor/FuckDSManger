# FuckDSManger 2.10.21（回复建议 · 在 `yp1.b()` 钩子里存档输入内容）

> 产物：`FuckDSManger_2.10.21_for_ds2.5.2.apk`（**172 / 2.10.21**，90 类，V1+V2+V3，sha256(partial) `94fda6c2…`）
> 触发：主人回报「仍然输入框空（有字版）」

## 一、排除掉的路径

| 尝试 | 结果 |
|---|---|
| 读字段 `yp1.b` | ✗（字段不存在 ⇒ 异常被吞） |
| 用捕获的 `yp1` 实例调方法 `b()` | ✗ 仍报「输入框空」 |

⇒ 很可能是 **`GmGateHook.sState` 捕获到的 `yp1` 实例不是当前输入框那个**（宿主可能有多个实例 / 每次重建）。

## 二、本版换路：在 `yp1.b()` 钩子里**存档返回值**

`yp1.b()` 是**宿主自己读取输入框内容**的入口（LSPosed dump 已确认 `java.lang.String yp1.b()`），
而我们**早就 hook 了它**（聊天区心跳就挂在这里）。

```smali
.method protected afterHookedMethod(…)V      ← 新增
    getResult() → Object
    instance-of String ?  → 存进 GmSeeHook.sLast
```

`hasText()` 改为：**优先读这份存档**（`GmSeeHook.sLast`），存档为空时才退回旧路径。

⇒ 这份存档是**宿主亲口读出来的当前输入内容**，不依赖"捕获的实例对不对"。
