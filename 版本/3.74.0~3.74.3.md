## 根因（3.74.0/2 的崩）

```
java.lang.IllegalArgumentException: Invalid ID: 46
  at android.graphics.ColorSpace.get
  at android.graphics.Color.colorSpace
  at android.graphics.Paint.setColor
  at y1c.c → zi9.a0(J) → zi0.J0
```
宿主 `zi9.Y(J)` 的原文：`if ((value & 0x3F) > 0xF) return value;`
⇒ Compose `Color` 把 **colorSpace id 藏在低 6 位**，不能瞎编 long。

## 3.74.3 的做法

不写任何宿主字段。在气泡绘制节点的 draw 之后：
1. 反射取 Canvas：`ah6.a→co1.a→bo1.c(wc)→wc.a`
2. `canvas.drawRect(0,0,w,h,paint)`
3. `okb.e` 的 `clip(t82.t)` 在上层 Modifier ⇒ 自动裁成气泡形状

配置：`fuckds_bubble_bg_on` / `_color`(signed ARGB) / `_alpha`
