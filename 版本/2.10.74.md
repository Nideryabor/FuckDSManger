## 一、① 隐藏一级菜单里重复的「回复建议」

`GmMenuDialog` 里那一项（副标题「AI 最新回复下方加一排追问按钮，点一下即发送」，`GmClick(0x33)`）：
在其 `v1.addView(v2)` 之后追加：

```smali
const/16 v3, 0x8
invoke-virtual {v2, v3}, Landroid/widget/LinearLayout;->setVisibility(I)V
```

⇒ 整项 `GONE`（与 2.10.73 隐藏「文件快捷选项」同法）。

## 二、② 修正「聊天」菜单项的对齐

**原因**：我 2.10.73 新建的项容器是「**垂直 + 无 padding**」，而现有项（防撤回 / 模型切换）的骨架是：

```
水平容器(v2)   ← setOrientation(0) + setGravity(16) + setPadding(dp(16))
  ├─ 内层垂直容器(v3) ← setOrientation(1) + LayoutParams(0, -2, 1.0f)【权重】
  │    ├─ 标题 TextView
  │    └─ 副标题 TextView
  └─（右侧控件，如 Switch）
```

**⇒ 照抄这套骨架后完全对齐。**

> ⚠️ 中途改容器变量时，我一度让后续 `setText` 仍按旧变量调用（`v3` 已是 LinearLayout）⇒ 会 `VerifyError`；**读回自检时发现并当场修正**。
