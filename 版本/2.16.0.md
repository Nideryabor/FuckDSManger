> 里程碑：**主人真机验证** —— 日志里第一次出现识别文字：

```
[通话] 命令 args[0]=fn1
[通话][ASR] 命令字段 a=这同样也是一条语音测试消息。 b=a635f97c-d59f-47fb-baa0-cb6932478136
```

## 一、定案：语音链路全貌（实测）
```
[点麦克风]  → 输入框切「按住说话」（Lhc5;->g = VoiceInputButton，点击 lambda = Li40）
[按住]      → AudioRecord.startRecording            ← 探针命中
[说话]      → 宿主对 /api/v0/asr/ws 流式识别
[松手]      → AudioRecord.stop（25ms 后）
            → ao1.J( fn1 )                          ← ⭐ 语音发送命令
                 fn1.a = 识别文字（String）
                 fn1.b = UUID（请求 id）
            → 宿主按自己的会话直接发出（所以"秒发"）
            → AI 回复 → 宿主 AutoTts 自动朗读（模块已注入 tts_feature，无需自写）
```
⇒ **"听 → 说"这条环，宿主自己走完了**；模块要做的只是**抓取 + 呈现 + 驱动状态**。

## 二、2.16.0 做了什么
| 改动 | 说明 |
|---|---|
| `GmCallHook`：读到 `fn1.a` 非空时 | ① 存 `sAsr` ② 通话页转录追加 **`👤 <你说的话>`** ③ 状态切 **「思考中…」** |
| `GmRecHook`：`AudioRecord.startRecording` | 状态切 **「聆听中…」**（＝闭环的"聆听"信号） |
| `GmRecHook`：`AudioRecord.stop` | 状态切 **「识别中…」** |
| （保留）`GmAsrHook` | `yp1.c` 写入对照探针（已修方向） |

⇒ 通话页现在的状态流：**聆听中… → 识别中… → 思考中… →（宿主自动朗读）= 待机**，且**你说的每句话都会以 `👤` 出现在转录区**。

## 三、复测
1. 装 **2.16.0** → 强停宿主 → 进对话 → 点 🎧 开通话页
2. **按住宿主的麦克风**说一句 → 松手
3. 期望：
   - 通话页出现 `👤 <你的话>`（＝识别文字）
   - 状态字依次滚过 聆听中 → 识别中 → 思考中
   - AI 的回复由**宿主自己朗读出来**（自动 TTS）
