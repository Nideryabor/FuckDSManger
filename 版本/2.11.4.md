## 一、问题：不知道 `dump()` 到底跑没跑

2.11.2 加了 `dump()`（打印非空字段），但主人发来的日志里**既没有 `F ` 行、也没有异常行** ⇒ **无法区分两种情况**：

| 情况 | 表现 |
|---|---|
| **`dump` 没被调用**（`grab` 没跑到） | 没有 `F ` 行 |
| **`dump` 跑了但字段全空** | 也没有 `F ` 行 |

⇒ **两种情况的下一步完全不同**（前者要查 hook 链路，后者说明正文不在 `nx` 里），必须区分。

## 二、本版：加两条标记

```smali
dump(p0):
    if (p0 == null) return
    log("dump begin")          # ★ 进入
    try { 遍历字段 … }
    log("dump end")            # ★ 走完
```

**⇒ 日志里：**
- **有 `dump begin` + `dump end`** ⇒ 跑了，但字段确实没内容 ⇒ **正文不在 `nx` 字段里** ⇒ 走 UI 路线
- **只有 `dump begin`** ⇒ 遍历途中抛异常（catch 里已加堆栈落盘）
- **一个都没有** ⇒ `grab()` 没执行 ⇒ 问题在 `wr.z` 的 hook 链路

| **457** | ⭐⭐⭐ **诊断代码必须"能自证执行过"**：只输出"结果"而不输出"开始/结束"，一旦没有结果，就无法区分"没跑"和"跑了没结果" —— **这两种情况的下一步完全相反** |
