## 二、本版修复：一招制胜

新增 **`GmPromptGateHook`** → hook **`dm0.g`**：

```java
args[0] = Boolean.TRUE;        // ★ 强制「显示提示词行」
args[7] = Integer.valueOf(0);  // changed bits 清 0，免得 Composer 跳过
```

注册：`hookM("dm0", "g", "…GmPromptGateHook")`

⇒ 闸门一开，下游（`nb5.c` → `yb5.e` → …）自然全部进入组合树，
之前写的 `prompt()`（改列表 + 强制可见）与 `fill()`（换 `yb5.f` 列表）**才真正有机会生效** ✓
