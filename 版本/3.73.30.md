## 一、这次的结论先说

`surf()`（也就是方案 B 的实现：**args[0] 挂图片 Brush + args[2] 置 0 透明**）在 **3.73.28 就已经写好了**，
不是没写；3.73.29 只是把诊断改成无条件。**两版都「看着没效果」，原因不是方案 B 错，是那道门。**

```smali
# 3.73.29 原文（surf 第一行逻辑）
invoke-static {}, GmBubble;->uOn()Z      # ← 读的是「**用户气泡**美化」开关 fuckds_ububble_on
move-result v0
if-nez v0, :cond_args
return-void                              # ← 这个开关一关，整段 60 行全不执行
```

`uOn()` = **用户气泡**开关。AI 气泡的美化开关叫 `on()`（`fuckds_bubble_on`）。
⇒ 只要「用户气泡美化」是关的，**AI 气泡的背景也跟着一起死**，而且**一声不响**。

3.73.30 把它换成 `imgOn()`：内部 `sUDepth>0 → sUImg`，否则 `sImg`，
**和下面选图名的逻辑同一口径**（选名也是 `sUDepth>0 → useUImgName()`）。

## 二、本版改动（全部在 `GmBubblePaintHook.smali`）

| # | 改什么 | 为什么 |
|---|---|---|
| 1 | **门槛 `uOn()` → `imgOn()`** | 上面那段。**本轮唯一的功能性改动** |
| 2 | 6 个 `early-return` 各加一条 `logOnce` | 教训 96：**跳过分支也要打日志**。原来 6 条全是无声的 ⇒ 「没效果」时无法区分是 hook 没跑、开关关着、图没解码、还是原语没找到 |
| 3 | 成功时打 `⑨ ✅ 已注入` | 一条就能证明「气泡真的被套上图了」 |
| 4 | 顶部「每帧无条件 DIAG」→ `logOnce` | 3.73.29 那样每次重组都拼字符串打日志，滑一下几百条，刷爆通道 |
| 5 | 新增 `sLog(String)` 私有助手 | 只干一件事：`GmUtil.logOnce(自己, 自己)` ⇒ 同样的句子只出一条，不刷屏 |

**这一版的设计意图**：哪怕还是不出图，日志也会**指名道姓**说卡在哪一步 —— 不再需要「再打一版试试」。

## 三、顺手修的一个坑：出包自检 ④ 的误报

`重建底座` 出来第一次 `做包` 就卡在：

```
✗ ④ 底座 dex 里有 2 个资源常量引用：['0x7e7c0000', '0x7f580000']
```

这两个值**在 smali 树里根本不存在**，`baksmali` 反编译回来也搜不到 —— 是**字节级误报**：

```
off=0x3274  ctx= e07e0100 a7010000 | 1400 0000 587f0100 a9010000
```

dex 数据区（`call_site_ids`）里 `14 00 00 00 58 7f 01 00` 被当成 `const 0x7f580000`。
（历史 3.73.1x 也栽过一次 `0x7e680000`，当时靠「别用 `const/16`」绕过去。）

**修法（`mod-src/pack/dexinfo.py`）**：新增 `code_ranges()` —— 按 dex 结构
`class_defs → class_data → code_off → insns_size` 算出**所有方法字节码的真实区间**，
`find_res_ids()` 只认「落在某个 code_item 的 insns 里、且 2 字节对齐」的匹配。
解析失败时自动退回老行为（宁可误报，不要漏报）。

自测：新底座 `res ids = []`（通过）；UI 的 `classes3.dex` 仍能报出常量（正样本没被弄哑）。

## 五、怎么验（一次就问清三件事）

1. **强停宿主** → 冷启动（`am force-stop` + `am start`，别只按返回）
2. 进一个**本进程从没打开过的会话**（Compose 缓存组合下，老会话整屏不重算）
3. 上下滑几下，然后看模块日志页（搜 `[surf]`）

判读表：

| 日志 | 说明 | 下一步 |
|---|---|---|
| 一条 `[surf]` 都没有 | `l23.a` 根本没被调用 / hook 没装上 | 看有没有 `[DIAG] 调用 len=7 m=a` |
| `①` | 图开关关着（或 `sUDepth` 判错作用域） | 把「AI 气泡 → 背景图」打开 |
| `⑥` | 图没解码出来 | 看同屏 `[气泡] …` 那条，多半是 `filesDir/fuckds_bubble.png` 不存在 |
| `⑦` | `GmPrims` 没找到刷子原语 | 看 `【GmPrims】刷子背景…` 那条，会写清是「参数个数 / 类型不匹配 / 没找到」 |
| `⑨` 但画面没图 | **注入了但被盖住** | 那就是宿主在别处又画了一层 ⇒ 走「after hook 读结果」那条路（见复盘 §5） |
