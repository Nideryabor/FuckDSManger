## 一、迁移

| 项 | 之前 | 现在 |
|---|---|---|
| 入口 | 调试 ›「系统提示词 v2（重构骨架）」 | **聊天 ›「系统提示词 ›」**（描述也改成"卡片式编辑：容器里的卡片按顺序拼成提示词"） |
| 页面标题 | 「系统提示词 v2」 | 「**系统提示词**」 |
| 旧的 `Pg("sysprompt")` 页 | 聊天页指向它 | **整块删除**（28 行：两张原理卡 + 6 项设置 + 指路卡） |
| 调试页的试装位 | 有一条 | **撤掉**（转正了，不该再躺调试菜单里） |
| 「自定义卡点 ▸」的兜底目标 | `"sysprompt"`（已删） | `"sysprompt_v2"` |

> `⋮ 更多` 里的承载设置（开启注入 / 注入模式 / 承载方式 / 包装前后缀）**早在 3.61~3.63 就搬进去了**，
> 所以这次删旧页**没有丢任何可调项**。

## 二、「猜你想跳转」跳转卡

在**音乐 / 回复建议 / 富文本**三页的**最顶部**各加一张卡：

```
┌──────────────────────────────┐
│ 猜你想跳转                     │
│ 去「系统提示词」看看 ›   ← 蓝色可点 │
└──────────────────────────────┘
```

* 它是 `JumpHintCard`（`Components.kt`），点蓝色那行 ⇒ `onNav("sysprompt_v2")`
* 文案按页面区分：音乐页是「去「系统提示词」调音乐变量 ›」
* 三个页面本来就是树里的普通页 ⇒ 跳转走现成的页面 id 栈（返回回到原页）
