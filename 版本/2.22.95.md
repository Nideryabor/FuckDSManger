## 1. ⭐ 新用法：**试验台 + 一次长按**

| 机制 | 状态 |
|---|---|
| **单击探针 → `试1`/`试2`/… 逐个（累积）消融** | ✅ **已验证能用**（主人正是靠它找到了 `cka.d:241`） |
| **🆕 长按探针 → 把"当前这个 `试N`"加入排除名单** | 本版新增 |

### 关键设计：**排除优先于消融**

`pg` 的判定顺序改成：

```
① 在排除名单里？      ⇒ 什么都不做（return）   ← ★ 最优先
② 在消融集合里？      ⇒ 置全透明（return）
③ 在透空白名单里？    ⇒ 半透明 50%
④ 都不是 ⇒ 不动
```

⇒ **长按之后，那个元素立刻恢复** ⇒ **你马上能看到"它回来了"** = 即时反馈 ✓（教训 237）

## 2. ⭐ 主人操作（**每一步都有即时反馈**）

1. 装 `2.22.95` → 强停 → 开 App → 进**你关心的那一页**
2. 「调试」页**拨开捕获器** → 返回 → **划一下**
3. **单击探针**：`试1` → `试2` → …（每一下都在累积消融）⇒ **盯屏幕**
4. **看到某个"你不想动的东西"被抹掉** ⇒ **长按探针** ⇒
   - Toast：**`已排除 xxx（它的底不会再被动）`**

5. **重复 3~4**，把该保的都长按排除掉 ⇒ **剩下的就是"可以透的层"** ✓

| 观察 | 结论 |
|---|---|
| 长按后 **Toast 出现 + 元素回来** | ✅ **成了** |
| 长按后 Toast 说「还没有试验目标」 | ⇒ 你还没单击切过候选 ⇒ 先单击一下再长按 |
