## 一、「文件快捷选项」为什么保存不了

模块里那套 `GmPrompt` 的数据是**两个模块侧键**：

| 键 | 含义 |
|---|---|
| `fuckds_prompt_feature`（`KEY`） | 用户在编辑器里填的 prompt_feature JSON |
| `kv_remote_settings_model_configs_v1`（`MK`） | **「宿主配置的快照」** |

而 `apply()`（保存路径）干的是：

```
src = 读 MK（宿主快照）
if (!ok(src)) return false;      ← ① 永远在这里失败
out = patch(src, 用户的)
存回模块 MK
```

**⇒ 那份「宿主快照」从来没有被填充过** —— 模块从没读过宿主的 MMKV，所以 `ok(src)` 恒假 ⇒ 保存失败 ⇒ 正是主人看到的 toast「**已保存，但未找到模型配置**」。

## 二、钥匙：宿主那份 MMKV 怎么拿

从宿主 `p66.<init>` 里翻到：

```smali
invoke-static {}, Lcom/tencent/mmkv/MMKV;->l()Lcom/tencent/mmkv/MMKV;   ← 无参静态 = 宿主默认 MMKV 实例
```

而它的读写包装是：

```smali
.method public final k(String,String)String         ← 读
    iget-wide v0, p0, MMKV;->nativeHandle:J
    invoke-direct {p0, v0, v1, p1, p2}, MMKV;->decodeString(J,String,String)String   ← 本体（native）
.end method

.method public final q(String,String)Z              ← 写
    invoke-direct {p0, v0, v1, p1, p2}, MMKV;->encodeString(J,String,String)Z        ← 本体（native）
.end method
```

⇒ **`k`/`q` 只是包装**，本体是 `decodeString` / `encodeString`（private native）。

## 三、⚠️ 顺手堵住一个大坑：我们自己会污染它

我们的 `GmMmkvHook` 挂在 `k`/`q` 上（把 `prompt_feature` 换成回复建议模板池）。
**如果模块自己用 `k`/`q` 去读宿主配置**，就会**再次被自己的 hook 改掉** ⇒ 编辑器显示的是模板池、保存的值也会被改成模板池 ⇒ 「文件快捷选项」彻底被我们劫持。

**⇒ 解法：模块自己走 native 本体**（`decodeString` / `encodeString` + `nativeHandle` 字段），**完全绕开挂在包装上的 hook** ✓

## 四、本版改动（3 处）

| # | 改动 | 说明 |
|---|---|---|
| 1 | **`GmPrompt` 新增 `host()`** | 反射 `MMKV.l()` → 取 `nativeHandle` → `decodeString(...)` 读宿主真实配置（绕过自己的 hook、全程 try/catch） |
| 2 | **`GmPrompt` 新增 `hostPut(String)`** | 同路径，用 `encodeString(...)` **把 patch 结果直接写进宿主 MMKV** |
| 3 | **`current()` / `apply()` 改走宿主** | `current`：优先 `host()`，失败才回落模块快照；`apply`：`host()`（或快照）→ patch → **`hostPut` 写宿主** → 同步快照，返回"是否真的写进宿主" |
| 4 | **停掉占用那排的两处注入** | `GmSuggestHook` / `GmSuggestHook2` 不再替换列表；`GmMmkvHook.handle` 直接返回（不再改写宿主配置） |

⇒ 现在：**那排 chip 完全还给宿主的「文件快捷选项」**，我们不再干预；编辑器的读写也都落在**宿主真实配置**上。

## 七、教训

| # | 教训 |
|---|---|
| **284** | ⭐⭐⭐ **模块自己要读写的数据，必须绕过自己的 hook**：否则 hook 会改自己（`decodeString`/`encodeString` 本体是最干净的绕法） |
| **285** | ⭐⭐⭐ **"找不到配置"先查"数据源"**：这套编辑器一半数据来自模块侧快照，而快照**从没被填过** |
| **286** | ⭐⭐ **本地缓存类字段（快照）要有"写入路径"**：只设计读取、没有填充，就是永久失效 |
