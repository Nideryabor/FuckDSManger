## 一、"没有 crash" 的原因：**捕手自己没装上（我的锅）**

48 版 `GmCrashHook.install()`：

```smali
instance-of v1, v0, Lcom/varuns2002/disable_flag_secure/gm/GmCrashHook;
if-eqz v1, :done        ← ★ v1==0（**不是**我们的 handler）就跳走 ⇒ 等于永远不安装
```

应该是 `if-nez`（已经是我们的才跳过）。
⇒ **反判断第 9 次**（教训 184 家族）。48 版的捕手**从未生效**，所以日志里当然搜不到「崩溃捕手」。

**修**：`if-eqz` → `if-nez`；另外在 `handleLoadPackage` **第一行**（版本日志之后）**再装一次**做双保险（`install()` 自带防重入）。

## 二、"点击图片上传就崩" 的最强嫌疑：`GmAvatarHook`

### 2.1 它挂在 `Resources.getDrawable` 上

```smali
.method protected beforeHookedMethod(…MethodHookParam;)V
    iget-object v0, p1, …->args:[Ljava/lang/Object;
    const/4 v1, 0x0
    aget-object v0, v0, v1
    check-cast v0, Ljava/lang/Integer;      ← ① 无 instanceof，直接强转
    …
    if-ne v0, 0x7f070059, :cond_3a
    … isOn / hasImage / drawable …
    invoke-virtual {p1, v1}, …->setResult(Ljava/lang/Object;)V
    sput-boolean TRUE, …sTold:Z
    const-string v1, "助手头像替换已生效"
    invoke-static {v0, v1}, …GmUtil;->toast(Landroid/content/Context;Ljava/lang/String;)V   ← ② 非主线程弹 Toast
    :cond_3a
    return-void                        ← ③ 整个方法没有 try/catch
```

三个问题叠在一起：

| # | 问题 | 后果 |
|---|---|---|
| ① | `check-cast` 无 `instanceof` 防护 | 参数形态变化即 `ClassCastException` / `NPE` |
| ② | **`GmUtil.toast` = `Toast.makeText(...).show()`，无 Looper/线程检查** | `Resources.getDrawable` **在后台线程也会被调用**（图片加载）⇒ 非主线程弹 Toast ⇒ **直接抛异常崩宿主** |
| ③ | **无 try/catch** | 任何异常（含 `GmAvatar.drawable` 解码失败/OOM）直接冒到宿主 |

**为什么"图片上传"必踩**：那条路径会加载大量 drawable（含 `0x7f070059`），且**常在后台线程**做。
⇒ 与主人现象完全吻合：**只有点图片上传才崩**。

### 2.2 同类问题：`GmResTextHook`

挂在 `Resources.getString` / `getText`（**超高频、也可能在后台线程**），同样是裸 `check-cast` + 无 try/catch。

## 五、教训

| # | 教训 |
|---|---|
| **270** | ⭐⭐⭐ **反判断第 9 次**：`if-eqz`（==0 跳）与 `if-nez`（!=0 跳）又写反，直接导致**捕手静默失效** —— 这类错误必须"写完立刻回读一遍" |
| **271** | ⭐⭐⭐ **凡是挂在系统方法上的 hook，必须有 try/catch + instanceof**：`Resources.getDrawable/getString` 是**全进程高频**入口，且**后台线程也调**，无防护 = 随机崩 |
| **272** | ⭐⭐⭐ **UI 操作（Toast/Dialog）绝不能在 hook 里裸调用**：hook 线程不可控，`Toast.show()` 在无 Looper 线程必抛 |
| **273** | ⭐⭐ **"只有某个操作才崩" = 那条路径独有的调用**：本例独有的是图片加载走 `getDrawable` ⇒ 顺着"该操作会碰哪些 hook"倒查，比通读代码快 |
