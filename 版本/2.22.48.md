## 1. 先排除掉的两个嫌疑

读完 `GmBgView`：

```smali
# <init>
    const/4 v0, 0x0
    invoke-virtual {p0, v0}, Landroid/view/View;->setWillNotDraw(Z)V     # false ⇒ 会调 onDraw ✓

# setup(mode, grad, alpha, bitmap)
    iput p1, p0, GmBgView->e:I        # e = mode
    iput p2, p0, GmBgView->f:I
    iput p3, p0, GmBgView->g:I        # g = alpha（onDraw 里 g*255/100）✓ 映射正确
    iput-object p4, p0, GmBgView->c:Landroid/graphics/Bitmap

# onDraw 分支
    if-lez v0, :cond_96   ; if-lez v1, :cond_96      # 宽高必须 > 0
    Paint.setAlpha(g * 0xff / 0x64)
    h ⇒ MULTIPLY / SCREEN / 不设
    iget v3, GmBgView->e:I
    if-nez v3, :cond_69                              # e == 0 ⇒ 画 bitmap
    iget-object v3, GmBgView->c:Landroid/graphics/Bitmap
    if-eqz v3, :cond_69                              # ★ bitmap 为空 ⇒ 落到渐变分支
    … drawBitmap …
    :cond_69  LinearGradient（若也为空 ⇒ :cond_96 什么都不画）
```

⇒ **`setWillNotDraw(false)` 没问题**；**字段映射也没问题**。
⇒ 剩下三种可能，全都能被一条探针分开。

## 2. 本版改动：把探针打进 `onDraw`

在 `onDraw` 的 `getWidth/getHeight` 之后的**第一条语句**位置插入（用 `logOnce`，只打一次）：

```smali
    const-string v12, "[背景] onDraw"
    invoke-static {v12, v11}, GmUtil->logOnce(String;String)V
    # v11 = "w=<宽> h=<高> e=<mode> g=<alpha> bmp=<位图对象或null>"
```

## 3. 主人验证 → 看这一行 `[背景] onDraw …`

| 日志 | 结论 | 下一步 |
|---|---|---|
| **完全没有** `[背景] onDraw` | **`onDraw` 根本没被调用**（尺寸为 0 / View 未 attach / 被父容器跳过绘制） | 查 `GmBgView` 实测 `getWidth/Height`、是否 `isAttachedToWindow`、`DecorView` 是否真的布局了它 |
| **有**，但 **`w=0` 或 `h=0`** | 图**没有尺寸** ⇒ 不画 | 说明 `LayoutParams(-1,-1)` 没生效（`DecorView` 不是 FrameLayout？）⇒ 改成显式 `MATCH_PARENT` 或插到 `content` |
| **有**，但 **`bmp=null`** | **位图没解码** ⇒ 落到渐变分支 ⇒ 无渐变 ⇒ 什么都不画 | 查 `GmBg.bitmap()` 的 `fuckds_bg.png` 读取路径 |
| **有**，且 `w/h/e/g/bmp` **全部正常** | **真的画了，但被上层盖住** | 查 `ComposeView` 是否 `SurfaceView`（独立 Surface 会盖住一切）；或把图**插到 `android.R.id.content` 内部**（少一层容器） |

## 4. 教训（824~825）

| # | 内容 |
|---|---|
| **824** | ⭐⭐⭐ **探针要打「在被怀疑对象自己内部」，而不是它的调用者**：2.22.47 的探针打在 `ensure()`（调用者），只能证明"插入动作发生了"；**图到底画没画，只有 `onDraw` 自己知道**。⇒ **分层排查时，每一层的探针要打在该层内部**，否则永远只能证明上一层没出错。 |
| **825** | ⭐⭐⭐ **「插进去了」和「画出来了」是两件事**，中间还隔着：**尺寸是否为 0 · Bitmap 是否为空 · 是否被 attach · 是否被父容器跳过绘制 · 是否被更上层的 Surface 盖住**。⇒ 一次把这些**全部**写进一条探针（`w/h/e/g/bmp`），比一轮一轮试快得多。 |
