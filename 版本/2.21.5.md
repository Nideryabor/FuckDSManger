## 一、为什么 2.21.4 还是圆（我上一版选错了）

主人追问「**如果还是个圆形呢**」⇒ 我没等回执，直接静态反编译了 `tt7` 的工厂：

```smali
.method public static final a()Lst7;              # ← tt7.a 的真身
    new-instance v0, Laz6;
    const/high16 v1, 0x42480000  # 50.0f          # ← 50% 圆角
    invoke-direct {v0, v1}, Laz6;-><init>(F)V
    new-instance v1, Lst7;
    invoke-direct {v1, v0, v0, v0, v0}, Lvf2;-><init>(Lxf2;Lxf2;Lxf2;Lxf2;)V
    return-object v1
.end method

.method public static final b(F)Lst7;              # ★ 宿主自己的「任意半径圆角矩形」工厂
    new-instance v0, Ln03;
    invoke-direct {v0, p0}, Ln03;-><init>(F)V       # PxCornerSize(px)
    new-instance p0, Lst7;
    invoke-direct {p0, v0, v0, v0, v0}, Lvf2;-><init>(...)V
    return-object p0
.end method
```

⇒ **`tt7.a` = `RoundedCornerShape(percent = 50)` = `CircleShape`** —— 和 `kq.d` 一样是圆！
（`tt7` 是宿主的「形状工具箱」：`a()`=圆、`b(px)`=圆角矩形、`c(4×px)`=四角各自指定）

### 顺带把这一族彻底搞清了（以后不用再猜）

| 混淆名 | 真身 | 依据 |
|---|---|---|
| **`az6`** | `PercentCornerSize`（`<init>(F)`，50.0f = 50%） | `tt7.a()` |
| **`n03`** | `PxCornerSize`（`<init>(F)` = px） | `tt7.b(F)` |
| **`vf2`** | `RoundedCornerShape`，构造 `(Lxf2;×4)`（4 个角） | `tt7` 的三处工厂 |
| **`st7`** | `vf2` 的子类（所以它没出现在 `.implements Lmd8;` 里） | `new-instance Lst7;` + `invoke-direct … Lvf2;-><init>` |
| `c84` | `RectangleShape`（`zc.o`） | 此前已证 |

> ❗ **复盘**：2.21.4 我只看「`tt7.a` 被宿主传给同一个 `Lmd8;` 参数位」就换了 —— **类型对，语义错**。
> 教训 651/652 说得很清楚：**要看宿主拿它画什么**。这次我直接去读工厂方法体，一眼就露馅（`50.0f`）。

## 六、教训

| # | 要点 |
|---|---|
| **654** | ⭐⭐⭐ **「类型对」绝不等于「语义对」——去读那个令牌的工厂方法体**：`tt7.a()` 里一行 `const/high16 … 50.0f` 就把「它是 `CircleShape`」钉死了。**看调用点只能猜用途，看工厂才是实证。** |
