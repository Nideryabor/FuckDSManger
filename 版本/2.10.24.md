## 二、★ 找到可见性本体

### 2.1 `Leb6.h1()` 的实现

```smali
iget-object v0, p0, Leb6;->e:Lnv6;          # 读 State e
invoke-virtual {v0}, Lnv6;->getValue()
iget-object v1, p0, Leb6;->f:Lnv6;          # 读 State f
invoke-virtual {v1}, Lnv6;->getValue()
invoke-static {v0, v1}, Lup4;->b(...)Z      # 比较 e 与 f
if-eqz v0, :cond_24
   iget-object p0, p0, Lo32;->b:Ljava/lang/Object;   # ★★ 返回的是【父类 o32 的 b 字段】
   check-cast p0, Lnv6;
   invoke-virtual {p0}, Lnv6;->getValue()...
```

⇒ **可见性本体 = `o32.b`（一个 `nv6` State）**；
`e` / `f` 只是两个"影子"，**只有它们一致时**才回落到 `super.b`。

### 2.2 前几版改错了对象

2.10.20 ~ 2.10.22 只改 `c1`/`i1`（= `e`/`f`），而且把两者都设成 TRUE ⇒ 它们"一致" ⇒
正好走 `super.b` 那条分支 ⇒ **改的字段完全没被读到** ✗

### 2.3 完整的渲染链

```
nb5.c（输入区核心 Composable）
  ├─ 算可见性 boolean → 写进 Leb6
  └─ 无条件调用 yb5.e(Leb6, List, …, Z, …)
        ├─ new z97(lambda 捕获 List) → remember(key=常量) ← 会复用第一次的 lambda
        └─ dm0.c(Leb6, …)                    ← ★ dm0.c = AnimatedVisibility 包装
              └─ 按 Leb6 的可见性决定是否渲染
                    └─ z97.f(...) → ca7 → yb5.f(List, …)   ← 列表行真正渲染
```
