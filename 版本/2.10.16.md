## 二、本版改动

| # | 改动 |
|---|---|
| 1 | 🆕 **位置微调器**：条上多两个按钮 **`↑` / `↓`**，每次 **±20dp** 实时移动（直接改 `FrameLayout$LayoutParams.bottomMargin` + `setLayoutParams`），并 Toast「[建议] 位置 margin=xxx dp」 |
| 2 | 🆕 **点击建议按钮 ⇒ 真的发送**：`GmSuggestView.onClick` ⇒ `GmSendRun.send(按钮文字)`（复用 2.10.14 已验证的发送链路）⇒ 点「展开讲讲」会真的发出一条消息 |
| 3 | 默认 `bottomMargin` **100dp → 200dp**（新增静态字段 `sMargin`，在 `<clinit>` 里初始化） |
| 4 | 点击**不再移除**按钮条（去掉「消失又重现」的怪现象） |

`onClick` 的新分派（**每个分支都标注了进入条件**）：

```
tag == "↑"  ⇒  sMargin += 20  ⇒ apply
tag == "↓"  ⇒  sMargin -= 20  ⇒ apply
其它（建议文案）⇒ GmSendRun.send(tag) ⇒ 结束
apply: 改 bottomMargin + Toast 当前值
```

## 四、怎么用（真机步骤）

1. 强停宿主 → 开 App → 进任意会话 ⇒ 按钮条出现在屏幕下方
2. 连点 **`↑`**，直到按钮条**正好贴在输入框上方**（每次 +20dp，Toast 会报当前值）
3. **把最终 Toast 上的 `margin=xxx dp` 数值回报** ⇒ 正式版就用这个值当默认
4. 点「展开讲讲」⇒ 应该**真的发出一条消息「展开讲讲」**（验证「按钮 ⇒ 发送」闭环）
5. 顺便测：**点输入框弹键盘**时，按钮条会被键盘盖住吗？
