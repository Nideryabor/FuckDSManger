## 一、这个 `-wal` 卡了三版

**怪事**：`dbSid` 的过滤条件读出来是**完全正确**的（`startsWith("deepseek_chat_")` + `endsWith(".db")`），**但它偏偏放进了 `deepseek_chat.db-wal`**。

**⇒ 不再跟"为什么"较劲**（读代码 → 改代码 → 再读，已绕了两圈），直接换**最笨也最稳**的办法：

## 二、`trySid0()` 入口硬挡

```smali
name = file.getName()
if (name.contains("-wal"))     return null
if (name.contains("-shm"))     return null
if (name.contains("-journal")) return null
… 继续（先 log "OPEN <name>"，再打开）
```

**⇒ 不管上游筛选怎么漏，SQLite 的伴生文件（`-wal` / `-shm` / `-journal`）一律**进不来**。**
