# FuckDSManger 2.9.21

> 🎯 **根因：一行写反的 if**。`sPrompted` 守卫用了 `if-eqz`，语义完全反了。
> 产物：`FuckDSManger_2.9.21_for_ds2.5.2.apk`（108 / 2.9.21，80 类，V1+V2+V3）

---

## 一、决定性日志

```
FuckDSManger: prompt ENTER
FuckDSManger: prompt SKIP already-prompted
```

`sPrompted` 明明是 **false**（第一次调用），却走进了「已弹过」分支。

## 二、根因

```smali
sget-boolean v0, GmDevice->sPrompted:Z
if-eqz v0, :already_        ← ❌ if-eqz = "等于 0 就跳"
```

⇒ **`sPrompted == false`（第一次）时反而跳去"已弹过"**，直接 return。

**正确**：`if-nez v0, :already_`（`sPrompted == true` 才跳）

### 这一个字符解释全部历史现象

| 版本 | 现象 | 解释 |
|---|---|---|
| 2.9.14 | 对话框不弹 | `if-eqz v0, :done` 同样反了 ⇒ 第一次调用就返回 |
| 2.9.15/2.9.16 | 加了手势、加了日志仍不弹 | 手势路径其实是好的，但**自动路径**一直是死的 |
| 2.9.18/2.9.19 | 只有 `promptIfNeeded called`，无后续日志 | 因为**在分支之前就 return 了** |
| 2.9.20 | 出现 `SKIP already-prompted` | 补的全分支日志终于把这一支照出来了 |

⇒ **`GmDeviceDialog.open()` 在此前所有版本里一次都没被执行过**（UI 层本来就是好的）。

## 四、教训（补充第十一节 —— 这条必须置顶）

| # | 教训 |
|---|---|
| **100** | ⭐⭐⭐ **`sget-boolean` + 守卫是头号杀手，且这次是"第一次调用走跳过分支"型**：<br>`if (flag) return;` 必须写成 **`if-nez v0, :ret`**。<br>**唯一可靠的检查法**：写完后**出声念**——"flag 等于 0 就跳过去返回"——念出来立刻就知道对不对。<br>本项目累计反向判断 bug 已达 **30+ 次**，其中 2.9.13 单轮 8 次、本条属于**最贵的一次**（连累 7 个版本） |
| 101 | **"全分支日志"是照妖镜**：2.9.20 把 `already` 分支也加上日志后，**一轮就锁定了根因**。此前 3 轮之所以瞎猜，就是因为那一支是静默的 |
| 102 | **构建后回读产物应该成为肌肉记忆**：本次靠它确认修复真的进了 dex（而不是又一次"以为改了"） |
