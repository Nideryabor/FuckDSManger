## 🎯 3.19.0 抓到的真凶

```
allKeys() 不可用（sp 实际类型 = com.tencent.mmkv.MMKV）
  ⇒ java.lang.NoSuchMethodException: com.tencent.mmkv.MMKV.allKeys []
getAll() 也不可用 ⇒ UnsupportedOperationException: ...Use allKeys() instead...
⇒ ⚠️ 两条路都不通，返回空表 ⇒ pin 表全量同步 0 条
```

**矛盾点**：方法不存在，但报错信息叫你用 `allKeys()`。

**唯一解释**：宿主跑过 **R8**，
- `getAll()` 是 `SharedPreferences` **接口方法 ⇒ 不能改名** ⇒ 点得到、抛得出那句写死的提示
- `allKeys()` 是**普通方法 ⇒ 被改名了**（提示里的 "allKeys()" 是字符串常量，不参与改名）
