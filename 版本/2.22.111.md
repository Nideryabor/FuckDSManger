## 二、四处改动

### 1. 入口类换血（核心）

| | 旧 | 新 |
|---|---|---|
| 类 | `com.varuns2002.disable_flag_secure.DisableFlagSecure` | **`com.nidyaber.fuckdsmanger.GmEntry`** |
| 形态 | 648 行手写 smali | **`GmEntry.java` 真编译**（javac → d8） |
| 包名 | 模板作者的名字（`varuns2002`） | 我们自己的 |

`xposed_init` 已指向新入口；旧的 `com.little_femaleboy...whale.DisableFlagSecure`（转发壳）
和 `com.varuns2002...DisableFlagSecure`（真身）**仍在 classes.dex 里躺着，但已无人引用**。

- 五个助手原样移植：`hookM / hookM2 / hookC2 / hookPickAll / hkAdd`
- 51 条 hook 注册**逐条对齐**（见第四节）
- 版本号日志同步为 `2.22.111`

### 2. 顺手修掉 `hkAdd` 的极性 bug

原 smali：

```smali
sget-object v1, GmCallDialog->sHookInfo
if-nez v1, :cond_c                 # ← 非空才跳过 append ⇒ append 只在 null 时执行
invoke-virtual {v0, v1}, StringBuilder->append(String)
```

`StringBuilder.append(null)` 出来的是字面量 `"null"` ⇒ **通话诊断对话框的自检串第一次
被拼出来就带了个 `null` 前缀**（`nullcom.ao1.I=3 | …`）。
按意图改成「非空才 append」。

> 字节码完全合法，手写时看不见；翻译成 Java 时一眼露馅 —— 正好是真编译的价值。

### 3. 自己造 manifest

`mod-src/pack/axml.py`（自己写的 AXML 编解码器）现造。
拿真实的 2.9.7 manifest 做过**往返测试：重编码后逐字节相同**（1548 B）。
本版与 2.22.110 的 manifest **只差 2 个字节**（versionCode `441→442`、versionName 末位 `0→1`）。

### 4. 换私钥 + 自造 APK

- 私钥 2026-09-25 生（4096-bit RSA · 30 年 · `CN=FuckDSManger, OU=Nidyaber, O=dxyabab, C=CN`
  · SHA-1 `32c8b057…`）—— 备份见 `巢穴/宝物库/签名钥匙备份-2026-09-25/`
- 封包：自己写 zip（`resources.arsc` STORED + 4 字节对齐）+ `apksigner` 签 V1/V2/V3
- 基础 `classes.dex` **一个字节没动**（原样搬运），我们的入口走 `classes2.dex`

## 六、这一版没做的

- **没有把模板那两个 `DisableFlagSecure` 从 dex 里硬删** —— 现在只是"没人指向它"。
  硬删要走 R8（`-keep` 整个 `gm.**` + 我们的入口，其余不可达即被裁）——留给下一版。
- **没有把别的 `gm/` 类搬进源码工程** —— 一次一个来，每搬一个就用同一套法子验等价。
- 未验项：真机（本版只做到静态闭环）
