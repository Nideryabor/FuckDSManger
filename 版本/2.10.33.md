## 二、剩下两个症状的根因推断

我们此前是**"就地改写宿主的老对象"**：

```smali
    host = p0.get(i)
    put(host, "c", 我们的文字)     ← 就地把文字写进宿主对象
    add(host)                     ← 加回列表的【还是同一个对象】
```

**Compose 以对象身份（identity）为键** ⇒ 身份没变 ⇒ 认为内容没变 ⇒
- 不重绘 ⇒ **文字不显示**（改的字段没被重新读）
- 点击闭包持有旧状态 ⇒ **点击没反应**

## 三、本版：造「新对象」+ 复制宿主的场景字段

```smali
    host = p0.get(i)                        ← 只为取它的场景字段
    inst = newInstance(g56, {Integer(0x2329+i), null, 文字})   ← ★ 全新身份 ⇒ 强制重绘
    put(inst, "b", host.getObjectField("b")) ← ★ 复制场景 ⇒ 保住点击逻辑
    put(inst, "c", 文字)                     ← 我们的文字
    put(inst, "d", null)                     ← 清掉资源 id（让文案回落到 c）
    putInt(inst, "a", 0x2329+i)              ← 我们的 id（文案钩子也认它）
    add(inst)
```
