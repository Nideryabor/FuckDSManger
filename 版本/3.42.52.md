## 一、逐条处理对照

| # | 主人反馈 | 处理 |
|---|---|---|
| ① | 「边缘那个」生硬、想圆角化 | **三处改造**：ⓐ 边缘带**限幅**（`band ≤ min(w,h)×0.34`）——小元素不再被带宽"吞掉"只留一条方缝；ⓑ 内圈与外圈**同心圆角**（形状路径内缩 / 圆角矩形内缩 `r-band`）；ⓒ 内侧加**过渡化开**（见 ②）⇒ 「生硬/方」的两大来源都摸了。**若还有方角：要截图继续磨**（见 §四） |
| ② | 颜色没有过渡、生硬 | **shader 级「边缘过渡」**：浓度从边缘往里柔和衰减（`fdmFade` 强度 / `fdmFadePx` 距离）。新键 **`fuckds_glass_fade`**（0–100，默认 **50**；0 = 旧的平铺样）。「仅边缘」时过渡距离 = 边缘带宽（内边自然化开）；「正常」时按元素尺寸自动取。**Haze 与 Cloudy 两套 shader 都改** |
| ③ | 取色器透明度对玻璃/气泡无效 | **玻璃：已修**——颜色自带的 alpha 现在**乘进浓度**（`a = tint × colorAlpha`；默认 255 不变）。**气泡：链路已查证**（取色器 alpha 一路直达 `colorLong`），详见 §五 说明 |
| ④ | 镂空不错，不用改 | 原样保留 ✅ |

## 二、实现细节（技术账，防"改了说不清"）

1. **shader 不手抄**：改 `参考/液态玻璃多方案/haze.agsl`、`cloudy.agsl` + `tools/gen_glass_shaders.py` 的公共前奏
   （新增 `fdmFade / fdmFadePx / fdmFadeFac(sd)`）⇒ 跑 `python3 tools/gen_glass_shaders.py` 再生成 `GmGlassShaders.java`（93 行净增）。
   - Haze：`aEff = tintColor.a * fdmFadeFac(sd)` 接进 over 合成；
   - Cloudy：`processColor(…, float4(tint.rgb, tint.a * fdmFadeFac(sdf)))`。
2. **uniform 兜底**：RIPPLE 方案没引用 `fdmFade` —— AGSL 可能剪掉未用 uniform ⇒ `setFloatUniform` 会抛 ⇒ **单独 try 兜住**（不拖垮整个 shader）。
3. **GPU 缓存键加 fade**（`SH_CACHE` key += `fadeAmt/fadePx`）——不然不同过渡参数的元素会**串用同一个 shader**（渲染串味的老坑）。
4. **边缘带限幅**：`band = min(cfg.edge×density, min(w,h)×0.34)`——小元素中心至少留 ~1/3 可见。
5. **颜色 alpha 乘算**（Sink）：`colA=(cfg.color>>>24)&0xFF; a = tint×2.55×colA/255`。
6. **配置快照 S / reload / toString / UI 行**（`fuckds_glass_fade`）同步加齐。

## 四、怎么验（以及"还不满意"怎么继续）

1. 冷启动宿主 → 开玻璃 → 形态「**仅边缘**」。

3. 「玻璃颜色」里**调透明度**看玻璃有没有立刻变透（③ 的验收）。
4. 若还有「方角 / 生硬」：**丢一张截图到上传区**（或告诉我"哪个元素、哪一档"），我按图定点磨 —— 「边缘那个圆角」我把能圆的都圆了，剩下要靠你的眼睛指路。

## 五、气泡透明度说明（③ 的后半句）

链路查证（静态）：取色器带 alpha → `cfg_put "i"` → 宿主 `getInt("fuckds_bubble_color")` → `sColor`（含 alpha）
→ `colorLong()` = `color << 32`（**alpha 在高位，没被吞**）→ 直接进气泡底。
⇒ **气泡颜色的透明度从代码上就是生效的**。你那天"没区别"最可能是两种情形：
**ⓐ 那张气泡开着「图片底」**（有图时颜色档本来就不显示）；**ⓑ 你调的是别的档**。
如果你在**颜色档**下复测还是没区别，喊我 —— 那就说明中间还有一个"影子"在盖（我去挖）。
