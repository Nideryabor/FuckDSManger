## 1. 究竟是哪几层（对照 2.22.49 日志）

```
bg#1  depth=0  why=1  v = #FF0F0F0F   ← 作用域外 ⇒ 没透明
bg#2  depth=1         v = #FF0F0F0F   ← 透明了 ✓
bg#3  depth=1         v = #FF0F0F0F   ← 透明了 ✓
bg#4  depth=0  why=7  v = #FF0F0F0F   ← 作用域外 ⇒ 没透明
bg#5  depth=0  why=1  v = #FF292929   ← ★ 颜色不是「页面底色」⇒ 没透明（内容区 surface）
bg#6/#7       u = LinearGradient(…)   ← 宿主自己的渐隐遮罩
bg#8  depth=0  why=1  v = #FFE5E5E5
```

**盖住图的就是这三层**：`bg#1`（更外）· `bg#4`（更内）· **`bg#5`（内容区 `#292929`）**

> 前两个因为「不在 ChatPage 作用域」被跳过，第三个因为「颜色不是页面底色」被跳过 ——
> **我连着两版各用一个条件去挡，每次都漏掉另一类。**

## 2. 本版判据：**按「最外的前 N 层」**（既不看作用域、也不看颜色）

```smali
pg:
  ① 方法名 == "v"
  ② args[1] 是 Long
  ③ sDepth == 0            ← 排除助手消息项内的气泡底
  ④ sPageCnt < 6           ← ★ 最外的前 6 层（覆盖 bg#1 ~ bg#5）
  ⇒ 透明化（args[1] = Long(0)）· cnt++
```

**为什么这样不会误伤**：

- `bg#1`~`bg#5` 都是**最外层**（页面底色 → 内容区 surface）
- 气泡、卡片、按钮等都在**助手项内**（`sDepth > 0` ⇒ 被 ③ 排除）或**更靠后的层**（被 ④ 排除）

**`why=` 编号（本版）**

| `why=` | 含义 |
|---|---|
| **1** | 方法名不是 `v` |
| **2** | `args` 问题 |
| **3** | 在助手消息项内（`sDepth > 0`） |
| **4** | 配额满（`cnt >= 6`） |
| **0** | ✅ 通过（`cnt` 已 +1） |
| **6** | `GmBg.real()` 为 false |
