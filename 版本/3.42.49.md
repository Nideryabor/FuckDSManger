## 二、根因（一行）

`tmp/base130_261/sm/.../gm/GmBubble.smali` → `GmBubble.inScope()`：

```smali
# ❌ 修复前
sget v0, sDepth
if-gtz v0, :cond_9      # sDepth > 0 ⇒ return false
invoke on()
return on()             # sDepth <= 0 ⇒ return on()
```

⇒ `inScope() = (sDepth ≤ 0) && on()` —— **方向反了**。
（老版语义（9/25、内联写法）：`on() && sDepth > 0` —— 只在助手消息项内做。）

`inScope()` 全库**唯一调用点** = `GmBubblePaintHook` 主逻辑（"项内小卡透明化"）：
- **D 分支**：把宿主 `qk7.D`（颜色背景）的 color 参数**刷成 `0`（全透明）**；
- **C 分支**：换 brush —— 已被 `brush()` 掏空成 `return null`（无害）。

⇒ 修复前它**在"项外"全量命中**：**全 App 的颜色背景（`qk7.D` 共 76 处调用点）被逐层刷透明** ⇒
「设置页/首页也透」「全 app 到处都透」（逐层刷 0、层间常有近似色，观感是"闷闷的透"）✓✓✓

## 三、修复（一行 + 注释）
