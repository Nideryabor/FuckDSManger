# 3.28.2（vc540）· 底座复用 2.22.131 —— 「改背景把助手图片改掉了」

> 2026-09-30 · 尼得亚伯 🐲 · 主人：「模块修改背景有 bug，选择图片并修改图片会把助手的自定义图片改掉，而背景变成渐变」

## 一、根因：UI 树里**写错了 kind**（一个字符串）

```kotlin
Pg("bg", "修改背景", listOf(
    ...
    It("选择图片", null, K.PICK, cmd = "avatar"),   ✗ 这一页发的是 "avatar"
```
⇒ 桥按 `kind=avatar` 路由到 **`GmAvatar`** ⇒ **选背景图其实是在给"助手自定义图片"写文件**，
而 `fuckds_bg.png` 从来没被写过 ⇒ `GmBg` 没图可用 ⇒ 画**渐变**（当时 `fuckds_bg_mode=1` 正好是"渐变"档）。

## 三、修法（两处）

| # | 位置 | 改法 |
|---|---|---|
| 1 | `fdm-app/src/Tree.kt` 「修改背景」页 | `It("选择图片", …, cmd = "avatar")` → **`cmd = "bg"`**（头像页那处保持 `avatar` 不变） |
| 2 | `FdmBridge.img_path` | 直拷分支从 `bubble/ububble` **扩到 `bg`**：拷到 `<filesDir>/fuckds_bg.png`，并顺手 **`GmBg.setOn(ctx,true)` + `GmBg.setMode(ctx,0)`**（自动开背景 + 切「图片」档）—— 否则"选了图也看不到"（mode 还停在渐变） |

## 六、教训

| # | 要点 |
|---|---|
| **1** | ⭐⭐⭐ **"一个字符串常量"能造成的破坏和一行逻辑 bug 等价** —— `cmd = "avatar"` 写在"修改背景"页里，症状却是"助手图片被换 + 背景变渐变"，横跨两个功能、两个进程（UI→宿主）。**"写错文件"类 bug 的第一反应：先看调用方传的 kind/key，再看被调方。** |
| **2** | ⭐⭐ **同一份 UI 树里，`cmd` 是"身份"，不是"备注"** —— 建议后续给 `Pg`/`It` 加一条自检：同一页内 `cmd` 不得重复、且必须属于该页允许的集合（像出包自检那样拦一道）。 |
| **3** | ⭐⭐ **"改完了不生效"要连"开关/档位"一起看** —— 这次就算图写对了，`bg_mode` 停在"渐变"也一样看不见图 ⇒ 选图动作应当**自带"开开关 + 切档"**。 |
