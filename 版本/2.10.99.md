## 一、"日志没捕获" = 崩在**我埋的网之外**

已埋网的位置：`pick()` / `ctxText()` / `grab()` / `sync()`（都有 catch）。

**而 `toggleAi()` 调 `probe()` 时是**裸的**** ⇒ probe 里任何异常都会直接穿透到按钮回调 ⇒ 宿主崩、日志空白。

### 本版：给 `toggleAi()` 加 try/catch

```smali
:try_start_tg
    probe(...) → toast(...)
:try_end_tg
.catchall {:try_start_tg .. :try_end_tg} :catchall_tg
    goto :ai_tg_done
:catchall_tg
    log(Log.getStackTraceString(e))          # ★ 完整堆栈落盘
    toast("AI 探测异常（已写日志）")            # ★ 界面可见
:ai_tg_done
```

**⇒ 从此"点按钮后崩"再也不会静默**：要么日志里有堆栈、要么 Toast 明确报"探测异常"。

## 二、顺便排查：`templates()`（渲染路径）

读了它的实现，**逻辑正确、无越界**：

```smali
sAi 非空 && !isEmpty() && aiOn() → return sAi      # AI 池优先
否则：text().split("\n", -1) → 按 count 截断，循环里有 array-length 边界检查
```

⇒ **不是 array 错误的来源。**
