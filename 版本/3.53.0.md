│                  │  ≡  曲名&歌手  ✕  │
│      封面         ├──────────────────┤
│                  │                  │

* 左列 `weight 1`：封面（`weight 1.15`）/ UI控件（`weight 1.0`）

### 各块里放了什么

| 块 | 内容 |
|---|---|
| **封面** | `ImageView` + `setClipToOutline(true)`（图片也跟着圆角）；从网易云 CDN 拉图（`?param=300y300` 取小图），**http→https 改写**，内存里只缓存最近一张 |
| **曲名&歌手** | `≡` 拖动把手 · 曲名 + 歌手（两行）· `✕` 本会话收起 |

| **UI控件** | 时间 + `SeekBar`（可拖，松手才 seek，避免拖动中反复 seek）+ `♪ ◀◀ ▶/❚❚ ▶▶ ↻` |

* `♪` = **拉起模块音乐页**（深链接，见下）
* `↻` 三态：`↻` 列表 / `①` 单曲 / `⤨` 随机

## 二、常驻 + 所有页面都在

* 挂载点仍是 `Activity.onResume/onPause` → `decorView.addView`
* **宿主是「单 Activity + Compose 导航」**（DeepSeek 就是）⇒ 页内跳转（会话页/设置页）
  **不换 Activity** ⇒ 我们那个 View 一直挂在同一扇窗上 ⇒ **天然就是"所有页面都在"** ✅
* 换 Activity（全屏页）时：`onResume` 里比对 `decor`，**不同就摘掉旧的再挂新的**
  —— 否则会在旧 Activity 上留残影
* 没在放歌也显示：「未在播放 / 点 ♪ 去选歌」+ 空封面 + 0:00

## 三、深链接（♪ 按钮）

`GmMiniBarView.openModule()` 发一个带 `page` extra 的显式 Intent：

```java
new ComponentName(FdmBridge.MODULE_PKG, "com.nidyaber.fuckdsmanger.MainActivity")
i.putExtra("page", "music");
```

→ `MainActivity` 读它 → `FdmApp(initialPage)` → `LaunchedEffect` 里入栈：

```kotlin
if (!t.isNullOrEmpty() && t != HOME && t != ABOUT) { stack = listOf(HOME); page = t }
```

⇒ 点 ♪ **直接落在音乐页**（不是首页）✅（真机截图确认）

## 四、播放器侧新增（为了卡片）

`MusicService` 的状态广播里补了：

| 字段 | 用途 |
|---|---|
| `cover` | 专辑图地址（卡片加载封面） |
| `pos` / `dur` | 进度（卡片画进度条与歌词高亮） |
| `lrcId` / `lrc` | 歌词。**换歌才推正文**（心跳只带 id）；`query` 时会带全 |
| `loop` | 循环模式 |

* **500ms 心跳**（`ticker`）：只在有播放器时跑，`onPrepared` 启动、`stopPlay` 停
* 换歌时**自动拉歌词**并缓存（`lrcCache` / `lrcFor`），拉到就补一次带歌词的广播
* 新增两条指令：`seek`（带 `ms` extra）/ `lyric`

## 八、教训

**958 · ⭐⭐⭐ 「用户没看见」先怀疑产品设计，不要先怀疑代码。**
尼尼上一版把「只有放歌才出现」当成贴心（不打扰），
结果主人**一次都没看到**这个功能 —— **看不见的功能等于不存在**。
涉及「常驻/显示」这类需求时，**默认就该让它出现**，
想安静可以做开关，但不能把"默认不出现"当默认。

**959 · ⭐⭐⭐ 跨进程的两半，要把「谁负责什么」写死在注释里。**
播放器在模块进程、卡片在宿主进程 —— 这种结构最容易出「两边都以为对方会做」。
本版的写法：**卡片只负责显示 + 发指令，播放器只负责播 + 广播状态**，
两边各自的方法名（`sendCmd` / `applyJson`）直接体现分工。

**960 · ⭐⭐ 用「配置读出来的值」自证「存-读链路通」。**
日志里那句 `迷你卡已挂上 MainActivity（313×202dp）` ——
尺寸不是硬编码的默认值，是从配置里读出来的 ⇒ **顺带证明了存取都对**。
日志里带上"来自配置的值"，等于免费多一条自检。
