## 一、两个问题
### ① `recOn()` 在**静默出口**返回了（自打脸：我自己的规矩"静默 return 一律补日志"）
`recOn()` 的静默出口有两处：`recGet()` 返回 null（拿不到 `xe1`）、`sAct` 为 null。
⇒ **2.17.2 全部补日志**：
```
[通话] recGet: 没有任何 ao1 组件（sAo1/sPairA/sNewA/sSeeA 全空）
[通话] rec: ao1.j 为 null
[通话] rec: 已取到录音控制器
[通话] rec: 取录音控制器异常（见上一条堆栈）
```
（另核实：`Lao1;->j:Lxe1;` **字段名/类型都对** —— 所以问题在"组件没抓到"或"取字段异常"，日志会直接点名。）

### ② `GmCallPTT.onTouch` 判断反向 ⇒ MOVE 被当成"抬起"刷屏
```smali
if-eq v0, 1, :chkcan   ❌ 不是 UP 才跳 ⇒ MOVE(2) 直接掉进"抬起"分支（刷屏根源）
if-eq v0, 3, :ret1     ❌ 是 CANCEL 反而跳过
→ 全部改 if-ne
```
现在：`DOWN`→开始聆听 / `UP`→抬起提交 / `MOVE`→忽略 ✓
