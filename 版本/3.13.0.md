## 一、改了哪条路

```
宿主设置页点「检查更新」
   ↓ 底座 GmEntryHook（抓 getIntField(thisObject,"a")==0x14）
   ↓ 本版之前： GmHomeUi.open()      ← 手写 smali 时代的 View 弹窗（已弃用）
   ↓ 本版之后： FdmUiHook 先拉起 Compose MainActivity
                ├─ 起来了 ⇒ setResult(null) 跳过旧弹窗
                └─ 没起来 ⇒ 原样放行，旧 View UI 顶上（兜底）
```

## 二、为什么用「挂 GmHomeUi.open()」而不是改底座

| 方案 | 评价 |
|---|---|
| 改底座 `GmEntryHook.smali` 那一行调用 | ❌ 底座是**二进制成品**（197 148 B / 128 类），为改一行要重造整个 dex；而且它是 `build_single.py` 原样搬的，一动就多一条回归面 |
| **hook 宿主那一行** | ❌ 宿主那行是**混淆过的**（判据 `"a"==0x14`），锚点随宿主版本漂移 |
| ⭐ **hook 我们自己的 `GmHomeUi.open()`** | ✅ 类是**我们自己的**，名字永不变；底座升级也不影响；失败自动回退到旧 UI |

→ 这也正好续上「入口分两层」的老思路：**底座一行不动，桥长在外面。**

## 三、动了 3 个文件

| 文件 | 改动 |
|---|---|
| `mod-src/src/…/bridge/FdmUiHook.java` | 🆕 换乘站：挂 `GmHomeUi.open()` → 拉起 Compose UI |
| `mod-src/src/…/bridge/FdmEntry.java` | 转发底座入口**之后**补一句 `FdmUiHook.install(...)` |
| `pipeline/build_ui.py`（MANIFEST 模板） | MainActivity 加第二张 intent-filter：`VIEW` + `DEFAULT/BROWSABLE` + `<data android:scheme="fdm"/>` |

### 3.1 两个必须写对的地方

1. **幂等但不误置位**：`install()` 先 `findClass(GmHomeUi)`，**找不到就静默返回、不置 `sInstalled`**
   —— 否则第一次在错进程（或底座没这份类时）空跑一次，**后面真正该装的那次就被自己挡掉了**。
2. **`sAct` 是包级私有字段** ⇒ 必须 `setAccessible(true)`
   （踩过的坑：`IllegalAccessError: Field … is inaccessible`）。兜底走 `ActivityThread.currentApplication()`。

### 3.2 拉起的两条通道

| 顺序 | 做法 | 为什么可行 |
|---|---|---|
| ① | `Intent(ACTION_VIEW)` + **显式 `ComponentName(MODULE_PKG, MainActivity)`** | 清单里 `<application android:forceQueryable="true">`（**本来就有**）+ MainActivity `exported=true` ⇒ 宿主看得见我们这个包 |
| ② | `Intent(ACTION_VIEW, "fdm://open")` + `setPackage(MODULE_PKG)` | scheme trampoline，兜底 |

两条都失败 ⇒ **不 `setResult`** ⇒ 旧 View UI 照常弹出，**绝不会「点了没反应」**。

## 五、真机怎么测（主人）

1. 装 `FDM-3.13.0-single-signed.apk`
2. **让宿主重启一次**（模块代码在宿主进程启动时加载）
3. 宿主 → 设置 → 点「**检查更新**」
   - 🟢 **期望**：直接开 Compose UI（桌面那个「FuckDSManger UI (单包)」那张脸）
   - 🟡 若还是旧 View 弹窗 ⇒ 说明两条拉起都失败 ⇒ 跑 `抓日志.sh`
4. 抓日志里看这几行（`GmUtil.log`，绝不去重）：

## 七、这一版记住的事

- **「弃用」不等于「删除」**：旧 UI 留着当兜底，比直接删掉安全得多
  —— 换乘失败时用户看到的是「旧界面」而不是「点了没反应」。
- **钩子要挂"自己的类"，别挂"对方的锚"**：对宿主是"抗版本漂移"，对底座是"不动二进制成品"。
- **幂等标志位只在真成功时置位**：`findClass` 失败的静默返回里，千万别顺手把 `sInstalled=true`。
