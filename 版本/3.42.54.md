# 3.42.54（vc597）—— 「半透明的墙」根因修复：输出 alpha 跟随「向内减色」

> 🐲 尼得亚伯 · 2026-10-02 夜

## 一、根因（一句话）

上一版只让**颜色层（tint）**向内淡出，而 **shader 的输出 alpha 恒为 1** ⇒
中心把颜色减光后，露出来的是"采样内容"（=元素原底色的合成实色）——
**就是主人说的"一堵半透明的墙"**；"看不出过渡/描边"同源：整块都在，哪里还有"边"。

## 二、修复（shader 级 · Haze + Cloudy 两套都改）

- 输出改为**预乘 + alpha 跟随 fade 因子**（`aFac = fdmFadeFac(sd)`）：
  - Haze：`return half4(outRgb * aFac, aFac)`
  - Cloudy：`return half4(outPix.rgb * aF, aF)`
- 语义：**边缘 aFac≈1 —— 与"很好看的半透明边缘"完全一致（原样保留）**；
  向里 alpha 渐减到 0 —— **真正化掉、透出底下页面** ⇒ 「过渡」「描边」自然显形。
- 「正常」形态同理：过渡=50 时中心半透（可调；过渡=0 = 旧平铺样）。
- 改动仍走 **.agsl 源文件 + 生成器**（没手抄一个字符）。

## 三、顺手加的两道保险

- **轮廓体检**：退化/异常路径（< 元素 55%）当"拿不到"处理（防裁剪切出"跑外面/变空白"这类怪相）。
- **仅边缘强制尝试拿形状**：即使"贴合"开关关着，仅边缘也自己去拿轮廓（它本来就靠这个吃饭）。
