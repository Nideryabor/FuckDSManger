# 2.10.20-probe（versionCode 138）

> 2026-09-18 · 「回复建议」第 21 轮：**改用「宿主原生 chip 行」方案**（主人提示）
> 一句话：主人提醒「上传图片/文件那里也有快捷输入」⇒ 龙龙去逆向宿主那排按钮，找到了它的**数据入口** ⇒
> **不再自绘 overlay**，而是把我们的建议直接塞进宿主自己的 chip 行 ⇒ 「做进输入框」的诉求天然满足。

---

## 一、为什么换方案

2.10.15 ~ 2.10.19 一直在自绘 overlay（a11y 定位 + 可见性控制），但始终摆脱不了
「**它不是输入框的一部分**」这个固有缺陷：切页残留、多行不跟随、要自己算键盘补偿…

主人提示：宿主**本来就有**一排「快捷输入」（上传图片/文件后出现）——
它天然就在输入框上方、只在聊天页、键盘自动跟随。

## 二、逆向结果（宿主 2.5.2 / vc273）

### 2.1 组件地图

| 混淆名 | 真身（来自 dex 里的 Kotlin 源文件名） |
|---|---|
| `Lnb5;->c(...)` | 聊天页**输入区核心 Composable**（843 指令；`.line 1595` 处调用 `yb5.e`） |
| `Lyb5;->e(Leb6;List;…)` | **`PromptTemplateView` 外层容器**（162 指令，源码行 137） |
| `Lyb5;->f(List;…)` | **列表行**（202 指令，含字符串 `promptCrossfade`） |
| `Lyb5;->c(Lg56;…)` | 单个 chip 按钮 |
| **`Leb6`** | **「提示词可见性」状态 holder**（内含两个 `nv6` State；`c1`/`i1` = setter，`h1()` = 读 boolean） |

### 2.2 ⭐ 关键发现：`yb5.e` 是**无条件调用**的

`nb5.c` 的 `.line 1595`：

```
move-object/from16 v1, v21
.line 1595
invoke-static/range {v0 .. v7}, Lyb5;->e(Leb6;Ljava/util/List;...)V
```

**调用点前面没有任何条件跳转** ⇒ 每次输入区重组都会调用 `yb5.e` ✔

⇒ 这也解释了 **2.10.0 探针为何 hook `yb5.f` 没命中**：可见性为 false 时 `yb5.e` 内部**不会走到 `f`**。

### 2.3 攻击面

| 参数 | 含义 | 我们能做什么 |
|---|---|---|
| `p0` = `Leb6` | 可见性状态 holder | 反射 `c1(TRUE)` / `i1(TRUE)` ⇒ **强制可见** |
| `p1` = `List<g56>` | 要渲染的模板列表 | **替换成我们的建议** |
| `p2`/`p3`/`p5`/`p4` | 修饰符 / 尺寸 / boolean | 不动 |

## 三、本版实现

新增 **`GmPromptHook`**（`beforeHookedMethod`）：

```
1) 参数不足 2 个 ⇒ 跳过
2) args[1] 不是 List ⇒ 跳过替换
3) 宿主列表非空（用户传了附件）⇒ 跳过替换（不打扰原功能）
4) 宿主列表为空 ⇒ args[1] = GmSuggestHook.build()   ← 我们的 3 条建议（单例缓存，避免无限重组）
5) args[0]（Leb6）非空 ⇒ 反射 c1(TRUE) + i1(TRUE)   ← 强制 chip 行可见
```

注册：`hookM("yb5", "e", "…GmPromptHook")`。

**同时停用自绘 overlay**：`GmSuggestHook.beforeHookedMethod` 里不再调 `bar(v0)`
（`GmSuggestView` / `GmSuggestHook.bar()` 保留备用，未删除）。

## 六、已知风险

| 风险 | 说明 |
|---|---|
| **宿主可能按 `scene` 过滤列表** | 我们传 `scene="default"`，宿主默认模板是 `image`/`file` ⇒ 有可能被过滤掉。若是，改成对应 scene 值再试 |
| 无限重组 | 已用单例列表（`GmSuggestHook.sList`）+ 同引用规避 |
| 组合期写 State | `c1/i1` 即 Compose `MutableState.setValue`；在组合中写会触发重组（正是我们要的），若异常会在日志体现 |
| 宿主升级 | 混淆名 `yb5` / `Leb6` / `nb5` 全部是 2.5.2 的名字，**升级后必须重新定位** |
