## 五、教训

**1045 · ⭐⭐ 加一个"资源"前，先确认打包链**真的**吃资源。**
　　我这次先查了三件事才动手：`fdm-app/res/` 有没有被 aapt2 编（有）、
　　`R.java` 是不是真生成（是）、出包后资源表里有没有那个 ID（有）。
　　⇒ 结论：**我们自己的 UI 可以上真图片/真 drawable**（不再是 3.58 时代那种"资源表空"的状态）。
　　★ 并且**出包后核验**（在 zip 里找那个 png + `aapt2 dump resources` 找那个 ID），
　　而不是"看构建日志没报错就当进了包"。

**1046 · ⭐⭐ 彩蛋的实现要**不依赖系统**、并且**失败无害**。**
　　· 计数只活在本页面（离开就重置）—— 不需要持久化，也就没有"卡在中间状态"的风险；
　　· 语言偏好存不上时**静默降级**（`try/catch` 吞掉）—— 彩蛋不该把页面搞崩；
　　· 文案集中在一处（`Lang.S`）—— 以后要加句子，只加一行。
