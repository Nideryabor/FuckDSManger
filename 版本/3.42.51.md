## 二、本版实现（三个新能力 + 三个新键）

### A · 贴合形状
- **形状接力**：组合期从 `qk7.D` 实参 + 元素字段抓 Shape ⇒ `sElementShape` ⇒ 随「元素→Node」接力 ⇒ `sNodeShape`。
- 绘制期：`createOutline(尺寸, 方向, 密度)` → Outline → **android Path**（`vv7.b→Lag.a`；拿不到就退"边界矩形"）⇒
  **玻璃按真实轮廓裁切/绘制**（圆角/胶囊/异形都贴合）。
- ⚠️ 宿主路径可能是**池化复用**对象 ⇒ 一律 `new Path(src)` 拷一份带走。
- 结果缓存 `node → [w,h,Path]`（尺寸不变不重算）。

### B · 镂空
- `cfg.form == 1` ⇒ **不画玻璃**、只把内容画回去 ⇒ 元素填充全透（元素自己的边框/内容若由别的元素画，天然保留）。

### C · 仅边缘
- 外轮廓 ∖ 内缩轮廓 = **边缘带**（`clipPath(outer)` + `clipOutPath(inner)`）⇒ 只在带里画折射/高光，中间透明。
- 内缩轮廓 = 用**同一个 Shape** 以 `(w-2b, h-2b)` 再 createOutline 一次 + `offset(b,b)`（和 Compose 自己画 inset border 同款算法）；
  拿不到形状就退回"圆角矩形内缩"。

### 新配置键（UI：液态玻璃页 3 行新控件）
| 键 | 默认 | 说明 |
|---|---|---|
| `fuckds_glass_fit` | **true** | 贴合元素形状（A） |
| `fuckds_glass_form` | 0 | 0 正常 / 1 镂空 / 2 仅边缘（B/C） |
| `fuckds_glass_edge` | 20 | 「仅边缘」带宽 dp（要盖得住折射带 pad，20 起步） |

> UI（`Tree.kt`）与宿主（`GmGlassCfg`）默认值一一对应；推送走既有 `cfg.fuckds_*` 通道，无需其它接线。

## 五、已知限制（v1，先上再看）

1. **GPU 折射的"边缘带"用的是半径近似**：形状是"非均匀圆角"（如上圆下不圆）时，折射的落点可能和真实边缘有几像素偏差 —— 下一步把真实轮廓参数喂进 shader 可根治。
2. **镂空/仅边缘**会让"由**同一个绘制节点**画的边框"一起消失（若边框是独立元素画的则天然保留）。真机上若遇到某元素"连边框都没了"，把这个元素告诉我。
3. 贴合依赖形状接力：第一帧可能先按旧圆角画、拿到轮廓后立刻变准（缓存后不再变）。
