## 二、这一夜的关键发现（按价值排）

1. **⭐⭐⭐ 反编译真机 `/system/framework/framework.jar` 查方法表** —— **不需要 root**，46MB 可读，能一次定死 API 签名。
   （`RuntimeShader.setInputBuffer(String,BitmapShader)` 就是这么查出来的 —— 猜成 `(String,Bitmap)` 白烧一版）
2. **⭐⭐⭐ 观察者效应**：frida 钩宿主调用链上的方法（如 `qk7.D`）会在栈里插帧 ⇒ `GmUtil.caller()` 数到它自己 ⇒ 被测对象行为改变。
   ⇒ **探针只能挂在被测链路的旁支上**（钩模块自己的类，caller() 本来就会跳过 `com.nidyaber.*`）。
3. **⭐⭐ 名字复用会"假成功"**：`mr.D` 存在但语义变成返回 `mb9` 对象；`pr6.o` 存在但类型从 `Lc84;`(Shape) 变成 `Lqt6;`。
4. **⭐⭐ `jq0` 结构变了**：`d` 从 `Landroid/graphics/Shader;` → **`Ljava/lang/Object;`**；`b(J)` 改成"按 tag 返回 d 里的东西"（tag=0→Shader，tag=1→RuntimeShader，默认→`lib` 包装）；**`J` 参数宿主根本没用到**。
5. **⭐⭐ `pg()` 的 10 项"调用点白名单"全是行号**（`zc.s:1417` / `uia.a:461`…）⇒ 新宿主行号全变 ⇒ **等于废的**，只剩 `sAblateCur.contains()` 那一道宽匹配在起作用。
