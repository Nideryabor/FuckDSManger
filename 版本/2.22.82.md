## 0. "和上一轮一样" ⇒ 我上一版的修法**没触及真因**

主人这句话本身就是信息：**叠加式消融**也没让它动。
⇒ 只剩两个假设，**这次我一次覆盖两个**（教训 199）。

### 假设 A：`args[1] = 0` 被宿主当成"未设置"

| 事实 | 推断 |
|---|---|
| 白名单写的是 **`0x80<<56 \| rgb`（非零）** | ⇒ **肉眼可见地生效了** ✅ |
| 消融写的是 **`0`** | ⇒ **零值很可能被宿主判成"没设置"，回退到默认色** ✗ |

**⇒ 修法：写「alpha=0 但数值非零」的颜色**：

```smali
const-wide v4, 0xffffff00000000L   # 高 32 位 = 0x00FFFFFF（A=0, RGB=白）
```

⇒ **视觉上完全透明，但 `v != 0`** ⇒ 绕开"零值特殊处理"。
（这正是白名单一直在用的套路 —— **保留 RGB、只改 alpha**，我在消融里却忘了，教训 197。）

### 假设 B：根本没命中

**⇒ 这次把命中数直接印在探针的字上，不用记 Toast**：

```
探针显示：  试3|25        ← "试3" = 当前累计 3 个目标；"|25" = 上一状态命中 25 次
            捕|0          ← 关闭
```

并且**每次点击的状态也写进模块日志 + 文件**（`GmDiag.log` + `GmLog.w`）⇒ 事后能翻。
