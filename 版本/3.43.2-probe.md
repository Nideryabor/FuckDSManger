## 一、让「缩放」真正起作用（**不是临时件，是正式改动**）

`GmBubbleFitHook` 里原来把 `zoomF()`（配置值）**只打日志**（"不封顶"是此前"不要空白"的取舍）。
本版改成**倍率**，乘到"按宽度铺满"的比例上：

```
最终 scale = (目标宽 / 图宽) × (配置值 / 100)
```
- **100% = 当前的"按宽度铺满"**（默认，观感不变）；
- **< 100%**：图更小，不够的地方由 CLAMP **边缘色**自然延伸（不是硬空白）；
- **> 100%**：裁得更狠（更放大）。

UI 同步改名：「最大放大 · 100 = 原大小」→ **「缩放 · 100% = 按宽度铺满（默认）；更小=图更小、四周补边缘色；更大=裁得更狠」**。
