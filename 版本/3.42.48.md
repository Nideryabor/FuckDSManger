## 二、本版改动（**只改一行逻辑**）

`GmBubbleFitHook`：

```smali
- invoke-static {v10, v11}, Ljava/lang/Math;->max(FF)F      # cover：放大+裁切
- move-result v10
+ # 直接用 v10 = W/bw（按宽度铺）
...
- mul-float v13, v9, v10     # 竖直居中
- sub/neg/mul ...
+ const/4 v13, 0x0           # 竖直不居中 ⇒ 图贴顶
```

⇒ **按宽度铺满（不放大、不左右裁切）+ 图贴顶 + 上下不够的部分交给 CLAMP 边缘色往下延伸。**
