# FuckDSManger 2.10.2（回复建议 · 定位「造不出 g56」）

> 产物：`FuckDSManger_2.10.2_for_ds2.5.2.apk`（**153 / 2.10.2**，86 类，V1+V2+V3，sha256(partial) `02525503…`）
> 触发：2.10.1 真机日志（主人 2026-09-19 08:35）
> 结论：注入点**完全没问题**，卡在「造 `g56` 对象」这一步 —— 本版把猜测换成**自动扫描 + 自验证 + 诊断日志**

## 一、2.10.1 真机日志说明了什么

```
[建议] 提示词容器命中（yb5.e/f）     ← ✅ 两道 hook 都活着
[建议] 宿主列表 list=4              ← 宿主自己有 4 条模板（不是空的）
```

| 判读 | 结论 |
|---|---|
| hook 命中 | ✅ `yb5.e`/`yb5.f` 都在渲染链上，**注入点选对了** |
| `list=4` | 宿主列表**非空** ⇒ 我 2.10.1 已改成「无条件替换」，所以不是被自己挡住的 |
| 画面没变成我们的 | ⇒ 只剩一种可能：**`build()` 造 `g56` 失败** ⇒ 返回 null ⇒ 我们不替换 ⇒ 宿主照旧显示自己的 4 条 |

**为什么造不出来**：2.10.1 用 `getDeclaredConstructor(Integer.TYPE, Integer.TYPE, String, String)`
（即档案里写的 `Lg56;-><init>(IILjava/lang/String;Ljava/lang/String;)V` / `mask=7`）。
但这条形态**从没在真机上真正执行过** —— 2.10.0 那版是 `NoClassDefFoundError`（没跑到构造器就挂了），
G.10.3 的「本来就对」只是**静态推理**。故本版不再赌签名。

## 二、本版改动（只动 `GmSuggestHook` 系列，业务逻辑不变）

| # | 改动 | 说明 |
|---|---|---|
| 1 | **`make()` 改成构造器扫描** | 遍历 `getDeclaredConstructors()`，挑出「4 参 + 第 3/4 参是 String」的那个，逐个试 |
| 2 | **新增 `tryCtor()` 自验证** | 造完立刻 `getObjectField(obj,"c")` 比对：**内容对上了才算成功**（防止"造出来但字段是空的"那种假成功 —— 正是档案里警告过的 `(ILjava/lang/Integer;Ljava/lang/String;)V` 那个把 content 写成空串的坑） |
| 3 | **新增 `dumpCtors()` 诊断** | 造不出来时，把 `g56` 的所有构造器签名一次性打到日志（`Constructor.toString()`）⇒ 下次直接照抄，不用再猜 |
| 4 | **日志分级** | `report()`（e）/`reportF()`（f）分开计数、分开打印 ⇒ **下次能分辨到底是哪个 hook 在干活** |
| 5 | **build 结果一行报** | `[建议] build 模板=3 造出=3`（或 `造出=0`）⇒ 一眼看出成功与否 |
| 6 | 设置界面加日志 | `[设置] 回复建议界面：打开请求` / `[设置] 回复建议：保存` ⇒ 排查「没有吐司通知」那条 |
| 7 | 版本串 | banner ×2 + Manifest → **153 / 2.10.2** |

## 三、真机验收（同一场景重跑即可）

```
1. 覆盖安装 FuckDSManger_2.10.2_for_ds2.5.2.apk（vc153）
2. 强停宿主 → 进会话 → 传一张图片
3. 抓日志，重点看这四行：
      [建议] yb5.e 命中（外层容器） / [建议] yb5.f 命中（列表行）   ← 谁在干活
      [建议] build 模板=3 造出=N                                  ← ★ 关键
      [建议] g56 构造器 → …（仅当 N=0 时出现）
4. 画面：输入框上方是否变成我们的模板池
```

### 判读表

| 现象 | 含义 | 下一步 |
|---|---|---|
| `造出=3` + chip 显示我们的 | 🎉 主干达成 | 进「不打扰附件 / 常显」 |
| `造出=3` 但画面还是宿主 4 条 | 列表换掉了但**渲染层没吃**（`remember(key=常量)` 锁 lambda / Composer skip） | 改从 `yb5.f` 单点注入 + 清 changed bits |
| `造出=0` + 有 `g56 构造器 → …` | 签名猜错了 | **照日志里那串签名改 `tryCtor` 的参数**（这版日志就是为此加的） |
| 只有 `yb5.e 命中`、没有 `yb5.f` | `f` 没被调用 | 只保留 `e`，并查 `remember` 缓存 |
| 连 `build` 行都没有 | 开关是关的 或 `app()` 拿不到 Context | 查设置里的总开关 |
