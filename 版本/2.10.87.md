## 二、只剩最后一步：从 `vq` 里"抽文本"

`ctxText()` 的拼接结果为空 ⇒ 说明 `one()` 对 9 个元素**全部返回 null** ⇒ 我调的 `vq.l()` 对这些元素不产出文本。

### 本版改动：**多方法试错**

新增 `pick(Object, String)`（试调一个无参方法并按需截断，内部 try/catch），`one()` 改为依次尝试：

```
l  →  t  →  k      谁先给出非空文本就用谁
```

全失败时，把**元素类名**写进 `sErr`（会显示在 Toast 的 `e=` 里）⇒ **一次就能看清 `vq` 到底该调哪个方法**。

```smali
.method static one(Ljava/lang/Object;)Ljava/lang/String;
    if-eqz p0, :one_null                  # 空对象直接返回 null
    pick(p0, "l") → 非 null 则返回
:one_t
    pick(p0, "t") → 非 null 则返回
:one_k
    pick(p0, "k") → 非 null 则返回
:one_fail
    sErr == null 时记下 p0.getClass().getName()
:one_null
    return null
.end method
```

> `pick()` 内部结构：`getMethod(name)` → `invoke` → `toString().trim()` → 空则返回 null → 超过 300 字截断。
