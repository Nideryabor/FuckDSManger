
## 二、根因：又是 `if-nez`（这次把**日志**掐死了）
```smali
# GmCallHook（读字段）
instance-of v5, v4, String ; if-nez v5, :nob   ❌ "是 String"时反而跳过 ⇒ 字段根本没读、没打
# GmAsrHook（yp1.c 探针）
instance-of v1, v0, String ; if-nez v1, :ret   ❌ 同上 ⇒ 输入框写入也从来没打出来过
```
⇒ 两处都改 `if-eqz`（"不是 String 才跳过"）。

## 三、`fn1` 的字段表（新侦察）
```
Lfn1; implements Lwm1;(=jn1 基类);  字段只有两个 ↓
  a:Ljava/lang/String;   public final
  b:Ljava/lang/String;   public final
  <init>(Ljava/lang/String;Ljava/lang/String;)V
```
⇒ 2.15.2 把**两个字段都打出来**：`[通话][ASR] 命令字段 a=<…> b=<…>`（同时把 b 存进 `sAsr` 备用）⇒ 下一份日志即可确认"识别文字在 a 还是 b"。
